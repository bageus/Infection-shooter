# template_game

Универсальный архитектурный шаблон для крупных игровых проектов, рассчитанный на совместную работу разработчиков и нейросетей.

## Главный принцип

Проект строится как **модульный монолит**: игровые возможности изолированы в модулях с небольшими публичными API, явными зависимостями и единственным владельцем состояния.

## Как начать

1. Любой AI-агент сначала читает [AGENTS.md](AGENTS.md).
2. Архитектурные правила находятся в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
3. Для нового модуля копируется [templates/module.json](templates/module.json) в соответствующий каталог внутри `src/`.
4. Архитектурное решение оформляется по [шаблону ADR](docs/adr/0000-template.md).
5. Перед завершением работы запускается:

```bash
python tools/validate_architecture.py
```

## Слои

```text
Bootstrap -> Presentation -> Features -> Core
        \-> Infrastructure -----> Core
```

Точные разрешённые направления зависимостей определены в [architecture/policy.json](architecture/policy.json) и автоматически проверяются CI.

## Что обеспечивает шаблон

- единый источник архитектурных правил;
- обязательные инструкции для AI-агентов;
- машиночитаемые границы слоёв;
- проверку циклических и запрещённых зависимостей;
- шаблон спецификации каждого игрового модуля;
- обязательное документирование архитектурных исключений.

Текстовые правила не могут физически запретить нейросети написать неверный код. Поэтому репозиторий сочетает инструкции, декларативные манифесты и автоматическую проверку.
