# Infection Shooter — оружие и текстуры v2

Комплект в едином low-poly стиле: четыре исходные модели с новыми текстурами, четыре новых модели оружия и отдельный боеприпасный рюкзак. Палитра: воронёный металл, светлые кромки, чёрный и коричневый полимер, оливковая краска, дерево, ткань и латунь.

## Исправления v2

Магазин, спусковой крючок и скоба АК состыкованы со ствольной коробкой. Рёбра магазинов АК и M4 следуют их контуру, утоплены в поверхность и проверены по границам. Сошки снайперской винтовки удалены. Атлас цвета пересоздан с гладким полимером и мелкой обработкой металла; рельеф нормалей уменьшен в несколько раз. Ткань назначена только элементам рюкзака.

`revision_geometry_validation.json` содержит проверки конкретных исправленных дефектов. В `scripts/check_weapon_revision.py` можно повторить проверку из каталога, содержащего `output/infection_weapon_pack_v2/`.

Авиационный пулемёт выполнен как игровая переносная версия шестистовольного минигана. Геометрия стилизована; это не точная техническая копия реального оружия.

У исходных четырёх моделей сохранены геометрия, нормали, имена узлов, трансформации и точки крепления. Добавлены UV, тангенты и PBR-материалы. Исходные файлы пользователя не перезаписаны. У новых моделей мелкие статические детали объединены по материалам; группы Magazine, Bolt, Scope и BarrelCluster остаются отдельными там, где они есть. Готовых анимаций и скелетов нет.

## Подключение

Скопируйте папки `models/` и `textures/` вместе, сохранив их взаимное расположение. GLB ссылаются на общие PNG через `../textures/`; перенос только GLB потеряет текстуры. Импортируйте нужный GLB в Godot как сцену. Материалы уже назначены в файле.

Новые модели: метры, +Y вверх, +X вдоль ствола. Исходные модели сохраняют авторскую ориентацию. Перед совмещением с существующей системой оружия проверьте её направление выстрела.

Точки новых моделей:
- `Muzzle`: выход ствола;
- `Grip_R` и `WeaponSocket_R`: основная рукоять/крепление;
- `Grip_L`: поддерживающая рука;
- `FeedPort`: соединение подачи у минигана и рюкзака;
- `BackSocket`: крепление рюкзака к персонажу.

Это позиционные маркеры. Направление выстрела нового оружия определяется +X корня модели; маркеры не задают готовую систему прицеливания. Гибкая лента между рюкзаком и оружием, коллизии, анимации, скрипты стрельбы и привязка к игровым сценам в комплект не входят.

## Атлас

Общий атлас 4 × 2, разбиение по материалам, а не по оружию:

| Слот | Материал |
| --- | --- |
| 1 | Воронёный металл |
| 2 | Светлый металл кромок |
| 3 | Чёрный полимер |
| 4 | Коричневый полимер |
| 5 | Оливковая краска |
| 6 | Тёмный орех |
| 7 | Ткань рюкзака |
| 8 | Латунь |

`textures/architecture_albedo.png` — цвет, sRGB.
`textures/architecture_normal.png` — tangent-space OpenGL (+Y), линейные данные.
`textures/architecture_orm.png` — R: AO, G: roughness, B: metallic, линейные данные. AO нейтральный белый: отдельное запекание окклюзии модели не выполнялось.

Имена `architecture_*` сохранены от общего сборщика атласов; это именно оружейные карты данного комплекта. Рабочие карты 2048 × 1024; `textures/master_4k/` содержит версии 4096 × 2048. Исходник цвета сгенерирован в размере 1774 × 887; 4K-версии увеличены из него, а не созданы с нативной детализацией 4K. Карты нормалей и шероховатости синтезированы художественно, это не фотограмметрические измерения.

UV — плоская проекция на гранях с ограничением внутри выбранного слота, без переходов на соседние материалы. Базовый масштаб узора 0,75 м, увеличивается для слишком больших поверхностей. Защитные поля: 16 пикселей рабочей карты, 32 пикселя 4K. Для очень дальних LOD при сильном mip-фильтровании проверьте отсутствие смешивания соседних материалов.

## Проверка и исходники

`validation.json`: проверка геометрии, сохранности исходных узлов, границ UV, нормалей/тангентов, отсутствие вырожденных треугольников, габариты и число треугольников.
`godot_import_validation.json`: импорт всех девяти моделей в Godot 4.7.2, создание сцен, наличие albedo/normal/roughness-карт на материалах. Это headless-проверка импорта, без проверки отражений в конкретном освещении игры.
`material_assignments.csv`: назначение материалов каждому GLB.
`atlas_layout.json`: прямоугольники и параметры материалов.
`previews/`: изображения настоящей геометрии с albedo и простым освещением; отражения PBR и normal-карта на этих превью не показаны.
`sources/new_model_geometry/`: геометрические исходники пяти новых объектов.
`sources/albedo_source.png`: исходник текстурного атласа.
`scripts/`: воспроизводимая сборка, UV/PBR-конверсия и рендер превью (Python, NumPy, Pillow).

Пересборка из каталога комплекта с четырьмя исходными GLB в отдельной папке:

```bash
python scripts/build_weapon_pack.py --inputs /path/to/original_glbs --source sources/albedo_source.png --output /path/to/new_output
python scripts/render_weapon_preview.py --models /path/to/new_output/models --output /path/to/new_output/previews
```

Скрипт проверки Godot содержит абсолютный путь к проверенной сборке; измените `folder` перед запуском на другом компьютере. Изменения в main-проект этим комплектом автоматически не вносятся.
