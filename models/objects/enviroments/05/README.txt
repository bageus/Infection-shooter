Группа 05: 22 цельные модели и загрузка повреждений по требованию.

Единый авторский атлас сохранён побайтово: atlas/05_shared_basecolor.png,
atlas/05_shared_normal.png, atlas/05_shared_orm.png. Исходники 2048²;
импорт albedo 2048², normal/ORM 1024², VRAM compression и mipmaps.
Параметры материала, включая linear → sRGB, сохранены в общих .tres.

Папка damage содержит только реальные стадии. Семь SmallFragments,
дублировавших LargeParts без более мелкой геометрии, исключены.
У шести GLB исправлено потерянное распределение узлов по стадиям.
UV, треугольники и все их атрибуты, трансформации и source_part сохранены.
Повторяющиеся вершины сварены без изменения развёрнутых треугольников.

Происхождение и размеры: asset_report.json. Стадии: lazy_stages.json.
Сборка из Git: python tools/build_group05_assets.py --apply
Проверка: python tools/check_group05_assets.py
Полный отчёт и ограничения: docs/qa/group05_assets.md.

Атлас пришёл из исходного пакета: отдельные поверхности мыши, телефона,
клавиатуры, лампы, мини-ПК и сушилки были восстановлены автором предыдущего
пакета; эта оптимизация не создаёт новые текстуры и не меняет их пиксели.
