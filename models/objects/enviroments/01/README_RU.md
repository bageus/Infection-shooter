# Подключение группы 01 в игре

Все 25 GLB расположены прямо в этой папке, на путях, которые используют существующие сцены и палитра. Модель полной стеклянной стены называется `01_glass_wall_full_breakable.glb`. Старые сохранённые пути с подпапкой `models/` и суффиксом `(1)` поддерживаются загрузчиком карт.

Каждый комплект использует свои три общие карты:

| Комплект | Моделей | Рабочие текстуры |
|---|---:|---|
| Стены, колонны, перегородки, окна, двери, VECTRION | 15 | `textures/architecture/architecture_*.png` |
| Ковры | 6 | `textures/carpet/carpet_*.png` |
| Лестницы и кабины лифта | 4 | `textures/stairs_elevators/architecture_*.png` |

Карты внутри GLB уже назначены. Цвет — sRGB; normal — OpenGL/glTF; ORM: R = нейтральный AO, G = roughness, B = metallic. Стекло, световые панели/дисплеи лифтов и резиновая окантовка коврика остаются отдельными материалами. Все файлы следует переносить вместе с папками текстур. Исходная таблица материалов сохранена в `sources/reference_metadata/material_assignments.csv` без импорта как перевода. Существующие верхнеуровневые карты и сведения ниже — исходные материалы загруженного комплекта; рабочие GLB ссылаются только на три папки из таблицы.

Геометрия, узлы, трансформации и поверхности сохранены; файлы источников/превью и облегчённые/4K reference-карты исключены из игрового импорта через `.gdignore`. Игра использует только назначенные карты 2K. Пол обычного уровня по-прежнему использует собственный шейдер плитки: эти текстуры меняют ковры и структурные модели, а не основной пол.

Проверка импорта, правильного комплекта карт, UV, тангентов, стекла, палитры и старых путей сохранения: `game/bootstrap/app/tests/run_group01_asset_tests.gd`. Проверка игровых коллизий и разрушения выполняется существующими тестами структурных моделей. Публичные API, DTO карт, зависимости и правила игры не изменены.

## Документация исходного комплекта

# Лестницы и кабины лифта — графитовый комплект

Четыре обновлённых GLB и общий PBR-атлас из восьми поверхностей. Исходные файлы не изменены.

Распакуйте весь комплект в проект, сохраняя `models/` и `textures/` рядом. GLB уже ссылаются на три общие карты и содержат UV и тангенты. Сначала проверьте новые ресурсы в отдельной папке проекта.

## Материалы

Нумерация в атласе: слева направо, сверху вниз, четыре столбца и два ряда.

| Участок | Поверхность | Использование |
|---|---|---|
| 01 | Графитовая краска | Ограждения, тёмные детали кабин, панели управления, направляющие |
| 02 | Светло-серая эпоксидная краска | Металлическая основа лестниц |
| 03 | Нескользящее гранулированное покрытие | Ступени и площадки лестниц |
| 04 | Тёмный мелкозернистый терраццо | Пол пассажирского лифта |
| 05 | Шлифованная нержавеющая сталь | Стены кабин, двери, поручни, кнопки, защитные полосы |
| 06 | Графитовая резина | Пол грузового лифта |
| 07 | Тонированная шлифованная сталь | Задняя декоративная панель пассажирского лифта |
| 08 | Светлое сатиновое покрытие | Потолки кабин |

Сталь имеет metallic = 1. Краска и напольные покрытия имеют metallic = 0. Наличие металлической основы под краской не делает покрытие металлическим.

Материалы `Light` и `Door_Gap` сохранены без изменения: световые панели и чёрные области дисплеев/зазоров остаются отдельными. Новые надписи, индикация этажей и источники света не добавлены. В исходных Light нет emissiveFactor; свечение и освещение нужно настроить в игровой сцене.

## Карты и качество

- `textures/architecture_albedo.png` — цвет sRGB.
- `textures/architecture_normal.png` — линейная normal map, OpenGL/glTF (+Y).
- `textures/architecture_orm.png` — линейные данные: R = AO (нейтральный белый), G = roughness, B = metallic.

Основной размер — 2048×1024. В `textures/master_4k/` находится вариант 4096×2048. Для его подключения скопируйте эти три файла в `textures/`, удалив `_4k` из имён копий. UV совпадают.

Цветовая основа создана встроенным imagegen; выходные карты масштабированы из генерации 1774×887. Размер 4K не означает нативный скан 4K. Normal и roughness — синтезированные художественные приближения.

UV рассчитаны проекцией по граням. Для боковых поверхностей направление шлифовки ориентировано вертикально; верхние поверхности проецируются на X/Z. Базовый масштаб участка — четыре метра; большие примитивы вписываются отдельно. UV находятся внутри своих участков, с защитными полями. Повторять весь атлас для тайлинга нельзя.

## Сохранение и проверка

Сохранены узлы, имена, трансформации, двери и кнопки как отдельные части, исходные позиции и нормали треугольников, число поверхностей и индексы материалов. Структурная проверка находится в `validation.json`. На швах вершины разделены, поэтому число вершин может увеличиться. Количество треугольников не менялось.

`godot_import_validation.json` содержит проверку импорта четырёх GLB, создания сцен и наличия всех трёх карт у текстурированных материалов. Игровая логика дверей, лифтов, коллизий и освещение не проверялись: они зависят от проекта и не входят в эти GLB. Общий атлас не объединяет поверхности и сам по себе не сокращает число draw calls.

`material_assignments.csv` — точное соответствие исходных материалов участкам. `atlas_layout.json` — UV-прямоугольники и параметры. `previews/atlas_materials.png` — подписанный обзор, не текстура для моделей.

## Повторная сборка

Нужны Python, numpy, Pillow, scipy и четыре исходных GLB.

```bash
python scripts/build_stairs_elevators_pack.py --inputs /path/to/original_glb --source sources/albedo_source.png --output /path/to/new_pack
```

Запрос для цветовой основы: встроенный imagegen, photorealistic-natural; точная сетка 4×2 из графитовой краски, светлой эпоксидной краски, нескользящего покрытия ступеней, тёмного терраццо, светлой шлифованной стали, резинового пола, тонированной стали и светлого потолочного покрытия; вид сверху, равномерный цвет без света, теней, надписей и рамок.
