# Группа 01: единый PBR-атлас v2

24 рабочие модели используют один комплект `textures/unified/group01_*.png`.
Тестовая `01_column_2.glb` и её три JPG сохранены без изменений и не включены в атлас.
Все существующие игровые пути моделей сохранены, кроме побайтового дубликата
`01_stairs_2.glb`: загрузчик старых карт перенаправляет его на `01_stairs.glb`,
включая прежнюю подпапку `models/`. Формат карт v8 не менялся.

| Карта | Исходник | Импорт в игру | Назначение |
|---|---|---|---|
| group01_albedo.png | 2048×2048 | 2048×2048 | Цвет sRGB |
| group01_normal.png | 2048×2048 | 1024×1024 | Tangent-space normal, OpenGL +Y |
| group01_orm.png | 2048×2048 | 1024×1024 | R: нейтральный AO; G: roughness; B: metallic |

VRAM compression и mipmaps обязательны. Проверенный GPU payload трёх карт:
4,67 МиБ в Godot 4.7.2 (накладные расходы renderer не включены).
Normal/ORM используют меньший размер для экономии памяти; UV-раскладка одинакова.
Поля исходного атласа 16 px, после уменьшения normal/ORM — 8 px.
Повторение всего атласа отключено. Защитные поля продолжены цветом края.

## Поверхности и материалы

`atlas_layout.json` содержит точные прямоугольники 12 покрытий и ковра.
Близкие покрытия согласованы: светлая эпоксидная краска лестницы использует
покрытие колонны, потолок — светлое покрытие, графит и сталь общие для всех моделей.
Для колонны добавлены крупная неоднородность roughness и небольшой normal-рельеф;
блики создаются освещением, в цвет не запечены свет или тени.
VECTRION — голый шлифованный металл: все три стадии назначены на brushed_steel,
metallic = 1 в синем канале ORM. Краска, дерево, резина и ковёр неметаллические.

`materials/` содержит три общих ORMMaterial3D: обычный, двусторонний и
затемнённый для Shaft_Dark. Последний сохраняет исходный линейный tint 0,45
(в Godot Color записан эквивалент sRGB). Инструмент
`addons/staged_glb_import/group01_material_post_import.gd` назначает именно
эти внешние ресурсы при импорте каждой модели, включая скрытые стадии разрушения.
Новый плагин не добавлен: используется существующий механизм post-import.
Стекло, световые панели/дисплеи и окантовка коврика остаются отдельными материалами.

## Геометрия и оптимизация

- Узлы, имена meshes, трансформации, число meshes и сцены стадий сохранены.
- Архитектурные треугольники и нормали сохранены точно.
- Ковры разделены по границам повторения UV в один метр: исходная плоскость,
  границы, площадь и нормали сохранены; дополнительный repeat-шейдер не требуется.
- Совместимые поверхности объединены только внутри одного mesh.
  Номера поверхностей стеклянных рам сохранены для отделения нижней панели.
- Количество поверхностей рабочих GLB: 461 → 393. Это не измерение draw calls
  всей миссии: скрытые стадии и проходы теней учитываются отдельно.
- Неиспользуемые изображения, accessors и буферы удалены; полные одинаковые
  вершины сварены без объединения UV и hard-normal швов.
- Physics-бюджеты разрушения и игровая логика не менялись.

Удалены 18 избыточных runtime-файлов и их .import (36,54 МиБ исходных файлов):
старые архитектурные/ковровые карты и их копии, четыре неиспользуемых PNG,
дубликат лестницы. Это размер удалённых исходников до учёта нового атласа.
Исходники, 1K/4K references и превью сохранены и исключены из импорта через
`.gdignore`. Прежние validation-отчёты перенесены в
`sources/reference_metadata/legacy_*.json`; они не являются проверкой v2.

## Проверки и повторная сборка

```bash
python tools/check_group01_atlas.py
python tools/check_group01_atlas.py --compare-ref 61e80037955ad211cb12055264381accd42ea0c2
godot --headless --path . --script game/bootstrap/app/tests/run_group01_asset_tests.gd
```

Проверяются ссылки, UV каждого треугольника, tangent vectors, отсутствие старых
буферов, metal tile, неизменность тестовой колонны, импортированные общие
ресурсы, mipmaps/compression, roughness после уменьшения и миграция лестницы.
Число поверхностей и размеры GLB записаны в `unified_validation.json`.

Для пересборки нужны numpy, Pillow, scipy (прежние зависимости authoring scripts)
и исходная папка группы из Git-коммита `61e80037955ad211cb12055264381accd42ea0c2`.
Экспортируйте её в отдельную папку; не запускайте builder на уже преобразованных GLB.

```bash
python models/objects/enviroments/01/scripts/build_unified_pack.py --inputs /path/to/original_group01 --output /path/to/new_pack
```

Builder пишет отдельный результат и не удаляет входные файлы. Рабочие .import
и внешние материалы берутся из текущего проекта: они задают разные runtime-размеры
карт и post-import. После изменения материала требуется переимпорт GLB.
Для просмотра раскладки используется `previews/unified_atlas.png`.
