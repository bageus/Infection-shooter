# Project state

## Current outcome
Каждая зона редактора сетапа имеет имя, тип обязательности и направление; стрелка показывает угол, который без случайного отклонения применяется к новым предметам. Угол регулируется числом и шагом 15°, изменение зоны поворачивает её существующие предметы. Формат шаблона версии 1 расширен необязательными полями с умолчаниями для существующих файлов.

Панель рабочего стола помещается в окне и прокручивается; старая подсказка больше не накладывается поверх него. Зоны и их предметы можно двигать вместе мышью или стрелками, поверхность и пол размечены сеткой, камера вращается вокруг стола. Для подсказки в обоих режимах есть кнопка `?`. Исходный формат шаблонов сохранён.

Для пистолета, автомата и дробовика подключены новые модели гильз из группы 12. При выстреле одна гильза выбрасывается сбоку оружия с вращением, физически падает и отскакивает; в общей очереди удерживается максимум 40 штук в течение 60 секунд. Архитектурная проверка проходит, игровую сцену локальный Godot не запускает из-за аварийного завершения до вывода ошибок.

Исправлен отсутствующий отступ в `workstation_templates.gd` после следующего скриншота владельца: он вызывал ошибку разбора и каскадно блокировал два скрипта редактора зон. Парсер принимает исправленные файлы; полный запуск Godot ещё требует проверки в рабочем редакторе.

Исправлена ошибка количества аргументов в `randf_range` редактора сетапов, обнаруженная вторым скриншотом владельца. Независимая проверка синтаксического дерева подтверждает количество аргументов у вызовов генератора случайных чисел и `Vector3`; запуск сцены в локальном headless Godot недоступен.

Исправлена синтаксическая ошибка редактора сетапа, из-за которой `planning_mode.gd` не мог предварительно загрузить новый скрипт. Парсер GDScript проходит; подтверждение в игровом редакторе требуется.

`07_table_square` теперь начинает с целой моделью без одновременно видимых крупных обломков из GLB. Для установленного офисного стола добавлен собственный режим редактирования зон и предметов, а также сохраняемые именованные шаблоны, переносимые между столами одного типа. Сохранения карт остаются версии 5; шаблоны сетапа имеют отдельную версию 1 и хранятся в пользовательских данных. Godot-проверка в текущей среде недоступна из-за аварийного завершения локального исполняемого файла.

Коллизия трёх видов остеклённых рам после разрушения стекла оставляет проём
проходимым. Пробитие пуль теперь расходует энергию по материалу и урон
снижается с дистанцией, включая попадания по заражённым. Крупные предметы и
стол требуют нескольких попаданий автомата либо дробовика; пистолет не
разрушает крупные объекты, стекло и мелкая техника остаются уязвимыми.

Архитектурные зависимости сцен, общей анимации и таблицы добычи приведены
к правилам модулей; семь прежних ошибок валидатора устранены без изменения
игровой логики. Генерируемая планировщиком авторская сцена теперь находится
в `bootstrap.app`, старые JSON карты читаются без преобразования.
Архитектурный валидатор проходит; общая проверка по-прежнему останавливается
на прежнем лимите размера `planning_mode.gd`.

Для пяти типов рабочих столов добавлены редактируемые профили и пять вариантов компьютерной техники. При размещении стола в планировщике автоматически создаются отдельные физические предметы с ограничением пересечений; расположение и связь со столом сохраняются в карте. Полный запуск Godot 4.7.2 ожидает проверки на стороне владельца.

Планировщик использует новый пакет `enviroments` вместо старой библиотеки и Office Set; 213 GLB распределены по группам 01–13 (в 13-й папке пять санитарных объектов). В режиме планирования видны красная точка центра, две оси деления и четыре точки в центрах квадрантов. Персонаж и враги продолжают использовать прежние модели.

Числовые поля планировщика снова принимают цифры с клавиатуры. Обычная и аварийная двери не перекрывают проём неподвижной коллизией при открытии; закрытые полотна продолжают блокировать проход.

Регрессия выбора объектов в палитре устранена; столешница после разрушения больше не удерживает оставшиеся ножки неподвижными. Все четыре ножки падают как отдельные физические тела.

Палитра больше не показывает восемь пунктов без моделей; нажатия в панели не создают объекты в мире. Для размещённых светильников доступны скорость/шаг мерцания и редкие отключения с сохранением параметров.

Тестовый стол теперь физически наклоняется к отстреленной ножке и быстрее падает без двух опор; попадание по центру разбрасывает столешницу и освобождает ножки. Физические предметы сверху получают импульс по направлению наклона. Оставленные обломки перестают препятствовать проходу.

По прямому запросу владельца тестовый `07_table` получил поэтапное разрушение, а пули — общие декали попаданий. После обратной связи исправлены нулевой масштаб деталей и коллизия исходного стола. Декали заменены на плоские меши для Compatibility; бюджет 40 общих следов и 40 остаточных обломков.
