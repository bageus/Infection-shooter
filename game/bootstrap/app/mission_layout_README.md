# Выход с уровня и гранатомёт

- Стартовый гранатомёт находится около центра левого верхнего квадранта
  планировки: `(-20, -15)`. Подойдите и нажмите **G**: активное оружие выпадет
  рядом с игроком, а гранатомёт займёт его место. Нажмите **V**, чтобы снова
  выбрать гранатомёт после переключения. **R** меняет барабан целиком и сразу
  выбрасывает шесть гильз. Магазин — шесть гранат.
- Ключ парит около `(20, 15)`; он подбирается при приближении без нажатия.
  Он открывает аварийную дверь около `(-20, 8.6)`, но враги сами дверь не
  открывают. На пороге дверь ждёт, пока персонажи отойдут.
- За дверью расположен спуск `x≈-20, z=10…24`. Точно под ступенями нет плитки
  и коллизии горизонтального пола; наклонная коллизия лестницы позволяет идти
  вниз и наверх. Спуск ниже пола завершает миссию.

Гранатомёт использует `models/objects/weapons/six_chamber_launcher_lowpoly.glb`
(ствол модели ориентирован по оси X и разворачивается к игровому дулу).
Гильза загружается из
`models/objects/enviroments/12/12_launcher_casing_lowpoly.glb`.
При отсутствии файлов игра использует игровые процедурные модели.
