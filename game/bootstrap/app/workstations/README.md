# Рабочие места

Планировщик поддерживает все модели столов группы 07, четыре офисных стола группы 08,
стойку ресепшена и книжные полки группы 03. Файл профиля каждого объекта лежит
в `desks/*.json`. Для полок `stations` описывают отдельные уровни с `grid_height`;
их зоны можно выбрать строкой соответствующего уровня, расставить книги и сохранить
через «Save template». Сохранённые шаблоны находятся в `user://desk_setups` и
применяются только к тому же типу исходной модели.

`grid_width` и `grid_depth` задают подсвеченную сетку, `usable_width` и
`usable_depth` определяют границы центра зоны. `zone_width`/`zone_depth` —
размер начальной зоны. Координаты заданы в локальных метрах модели. На одной
полке может быть несколько уровней с одинаковыми X/Z и разной высотой; выбор
строки позволяет управлять каждым уровнем независимо. Дублируйте зону для
нескольких стопок книг и назначайте ей тип «Книги».

При установке другого экземпляра модели планировщик применит случайный
сохранённый шаблон, слегка сместив предметы внутри их зон. Предметы остаются
связаны с основой и сохраняются вместе с картой. Если модель импортирована с
другим началом координат, поправьте размеры и высоты её JSON-профиля.
