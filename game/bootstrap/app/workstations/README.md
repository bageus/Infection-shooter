# Рабочие места

При размещении в планировщике одной из пяти моделей стола создаётся рабочее место.
В `desks/*.json` указаны координаты рабочих поверхностей, их высота, места для
кресла, урны, тумбочки и редких дополнительных предметов. В `setups/*.json`
описаны пять сочетаний компьютеров. Позиции заданы в метрах относительно
центра рабочей поверхности: сидящий смотрит вдоль положительной оси Z, X —
слева направо. `angle` разворачивает рабочее место на столе; `floor: true`
ставит предмет на пол под столом.

Обязательные мышь и телефон добавляются программно. Для каждого варианта
`laptop`, `monitor`, `tower`, `chair`, `bin`, `lamp`, `paper`, `small` используется
случайная модель из списка `VARIANTS` в `workstation_templates.gd`. Новые
варианты модели добавляются туда только после проверки фактического `.glb`.

Каждая поверхность получает один из пяти наборов. Позиции немного смещаются,
предметы поворачиваются на ±6°, а генератор отвергает модели с пересечениями.
Содержимое создаётся отдельными физическими объектами. При перемещении стола
в планировщике они перемещаются вместе с ним; отдельный предмет можно удалить
или поправить вручную. При удалении стола удаляются все его автоматически
расставленные предметы. Сохранение карты хранит готовые предметы и их связь
со столом, поэтому повторная загрузка не создаёт дубликатов.

Если на поверхности недостаточно места, конфликтующий предмет пропускается.
В отдельных повреждённых или непропорциональных GLB содержимое нужно проверять
визуально после импорта в Godot 4.7.2; для такого стола корректируйте координаты
и высоту в его профиле.
