# Мутации

В режиме игры нажмите **M**, чтобы открыть дерево. Верхняя полоса — активные
навыки, нижняя — пассивные. Очки появляются с ростом мутации; для последовательных
навыков нужны предыдущие узлы ветки, а для гибридов — обе соседние ветки.
Нажатие на незаполненный кружок расходует очко; нажатие на замок справа от
изученного узла сохраняет его при снижении мутации. Сохранённый узел вновь
заработает при достижении нужного порога. Незакреплённые узлы ниже порога
исчезнут и потребуют повторного распределения очка.

Полученные активные навыки отображаются на прокручиваемой панели внизу.
Первые четыре запускаются клавишами **4–7**, остальные — кнопками на панели.
У каждого навыка откат. **F** — обычный удар вблизи; пассивный навык «Когти»
усиливает его.

Постоянное облако мутагена для тестирования находится в центре карты (0, 0, 0).
В отличие от облаков с убитых врагов, оно не исчезает и постоянно накапливает
мутацию, пока игрок стоит внутри.
