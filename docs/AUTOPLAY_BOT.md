# Бот автопрохождения (QA)

`tools/autoplay_bot.gd` играет карты теми же входами, что игрок (действия move/sprint/fire/roll/reload/antidote/weapon_N и курсор через `player.aim_cursor_override`), без читов. Каждую карту проходит на трёх сложностях (низкая, обычная, высокая), бьёт ящики с лутом, подбирает патроны, аптечки и антидоты и пишет отчёт.

```bash
tools/run_autoplay.sh maps=level_1,level_2 difficulty=all duration=180   # headless
RENDER=1 tools/run_autoplay.sh maps=level_1 difficulty=2 duration=300    # с окном (для железа Vadim)
```

Аргументы: `maps=<имена|all>` (имена как в `campaign_config.json`, `all` берёт кампанию без tutorial), `difficulty=<0,1,2|all>`, `duration=<игровые секунды на прогон>`, `out=<путь без расширения, по умолчанию user://autoplay_report>`, `seed=<int>`, `list`. Перед первым запуском проект должен быть импортирован (`godot --headless --import`). `--fixed-fps 60` ускоряет прогон относительно реального времени. Для трассы взрывов добавьте пользовательский аргумент `explosion-trace`.

Отчёт (`.md` и `.json`): результат прогона, минимум здоровья, урон, убийства, потрачено/найдено патронов, секунды без патронов, найденные и подобранные аптечки/антидоты/патроны, сколько ящиков с лутом разбито, места застреваний, кадры дольше 50 мс (с позицией героя), FPS и p95/p99, ошибки скриптов (через `Logger`), хвост `frame_spikes.log`. Вердикт сложности: «слишком лёгкая» (прошёл с ≥70% здоровья и без нехватки припасов), «сбалансирована», «впритык по припасам», «слишком тяжёлая», «неопределённо» (вышло время). Заметки AMMO/MEDKITS/ANTIDOTES появляются, когда припасов не хватило дольше 3 с без пикапов и ящиков рядом.

Код выхода 0 без ошибок, 1 при ошибках скриптов или карте, что не загрузилась. Движок иногда падает при завершении после нескольких карт (`corrupted size vs. prev_size`), поэтому обёртка берёт код из строки `AUTOPLAY exit_code=`.

Не покрыто: гранаты (в игре нет действия гранаты), мутационные навыки, ключи и закрытые двери. Шаблонные карты находятся по `res://content/levels/<имя>.json`, иначе по `user://maps/<имя>.json`; в репозитории этих карт нет.
