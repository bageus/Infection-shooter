# Размер репозитория: план перехода на Git LFS

Состояние на 05.10.2026: `.git` ≈ 445 МБ, рабочее дерево ≈ 438 МБ
(GLB/FBX ≈ 214 МБ, PNG/JPG ≈ 208 МБ). В истории ≈ 318 МБ удалённых `.blend`.
Каждый клон и каждый CI-прогон скачивает всё это.

## Уже сделано (без переписывания истории)

- Удалены 159 неиспользуемых `models/objects/textures/Image_*.png` (12 МБ).
- Из git убраны сгенерированные файлы (`__pycache__`, отчёт аудита моделей);
  `.gitignore` покрывает сборки, кэш Python, бэкапы Blender.
- `export_presets.cfg` (Windows, Web) не кладёт в сборку исходники врагов
  (`models/objects/characters/enemy/*.glb` и их `*_N.jpg`, ≈ 140 МБ),
  тесты, инструменты, документацию и плагин редактора.
- Дубликаты текстур (59 групп, ≈ 10 МБ) — в основном картинки, которые Godot
  сам извлекает из GLB рядом с моделью; удалять их бессмысленно, импорт
  создаст их снова. Экономия придёт с LFS (одинаковые файлы хранятся один раз).

## Проверено и решено (05.10.2026)

Переписывание истории выполнено на копии и проверено (все 6 веток
совпадали побитово), но **не опубликовано** — по решению владельца:

| Что | Размер упакованного репозитория |
|---|---|
| Сейчас, вся история | 417 МБ |
| После удаления из истории 362 исчезнувших бинарных путей (87 .blend, 169 .fbx, 73 .glb, …) | 366 МБ |
| Только текущая версия, без истории | 327 МБ |

- Оценка «318 МБ .blend» была размером без сжатия; в git они сжимаются и
  весили немного. Выигрыш — около 50 МБ (12 %), а основной вес — текущие
  ассеты.
- Ссылки GitHub на старые PR (`refs/pull/*`) удалить нельзя, они держат
  старые объекты на сервере, так что серверный размер почти не меняется.
- Цена (все клоны пересоздать, push из старой копии вернёт историю) не
  стоит 12 %, поэтому история оставлена как есть.
- Git LFS не используется: бесплатная квота — 10 ГБ скачиваний в месяц, и
  скачивания CI в неё входят; при ~420 МБ ассетов на прогон квота
  кончилась бы за 1–2 дня, после чего LFS блокируется до конца месяца.

## Как сдерживать рост дальше

- Не коммитить промежуточные версии больших GLB/текстур: каждая новая
  версия модели — новый полный объект в истории.
- Исходники (`.blend`, исходные GLB врагов) держать вне репозитория или в
  `.gdignore`-папке, если они не нужны для сборки.
- Если репозиторий всё же станет мешать (например, > 1 ГБ), повторить
  переписывание: `git filter-repo --invert-paths --paths-from-file …`
  по путям, которых нет ни в одной ветке, затем force push и переклонирование.
