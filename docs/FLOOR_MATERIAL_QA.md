# Проверка материала базового пола

Три production-файла находятся в presentation.office_floor. Две общие NoiseTexture2D 256×256 с mipmaps добавляют малоконтрастную фактуру и вариацию шероховатости. StandardMaterial3D совместим с Forward+ и Compatibility; нового шейдера нет. Metallic=0, specular=0.35; оттенки плиток различаются в пределах ±3%. Шестнадцать материалов разделяют две текстуры, включая четверти плиток с уменьшенным UV scale. Оттенок выбирается hash(Vector2i) родительской ячейки, повторяется после перестроения в текущей версии движка. Зазор визуальной сетки сужен 15→2 мм изменением ширины меша 1.985→1.998. Высота/центры/коллизии/отверстия прежние.

## Приёмка

1. Сравнить одинаковые камеру, разрешение и освещение до/после; лампы не переключать ради материала.
2. Фактура едва заметна, нет разноцветной шахматной доски или зеркального пола.
3. Швы не доминируют; нет z-fighting и мерцания при движении/зуме.
4. На полу читаются кровь и попадания. Проверить обе сборки.
5. Перестроить лестничные отверстия: они остаются свободными, масштаб grain четвертей сопоставим с целыми плитками.
6. Перезапустить сцену: оттенки сохраняются. Измерить стоимость на одном маршруте.
7. Для отката вернуть три production-файла из parent commit; миграция карт не нужна.

## Проверки

До автоматической очистки workspace локальные validate_project и три scene-access tests прошли. Godot локально отсутствует; восстановленные изменения проходят стандартный CI. Визуальная приёмка и измерения FPS не выполнены.
