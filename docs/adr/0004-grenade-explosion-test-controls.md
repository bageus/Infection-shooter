# ADR-0004: Переключение вариантов взрыва из HUD

- Status: accepted
- Date: 2026-09-29
- Owners: bageus
- Related modules: features.combat, bootstrap.app, presentation.prototype_hud

## Context

Владелец запросил игровую кнопку для сравнения двух вариантов взрыва.
Клик не должен одновременно выпускать гранату; D уже используется для движения.

## Decision

HUD предоставляет отдельную кнопку `ExplosionVariant`, bootstrap связывает её
с выбранным оружием. В публичной сцене гранатомёта доступны команды
`toggle_explosion_variant()` и `set_test_controls_hovered(bool)`, запрос
`get_explosion_variant()`. Состояние варианта и запрета выстрела при наведении
принадлежит combat. HUD не получает новую зависимость от combat.
Публичные пути сцен и форматы сохранений остаются прежними.

## Alternatives considered

- Перехват D отвергнут из-за существующего управления движением.
- Изменение состояния оружия прямо из HUD отвергнуто: UI не владеет этим состоянием.

## Consequences

Кнопка доступна только с гранатомётом и меняет вариант следующих выстрелов.
Bootstrap перехватывает нажатие/отпускание до GUI и игровой обработки; попадание
курсора проверяется в координатах кнопки с учётом canvas-преобразования.
Блокировка выстрела покрывает текущий и следующий физические кадры клика,
включая быстрое нажатие/отпускание и перетаскивание за границы кнопки.
Отвод мыши или смена оружия снимает запрет выстрела. UI может не показать
изменение до следующего кадра; текст также обновляется сразу после нажатия.

## Migration plan

Добавить команды к существующей сцене оружия, кнопку HUD и bootstrap-связку.
Существующие карты, слоты оружия и снаряды сохраняют совместимость.

## Rollback plan

Удалить кнопку, bootstrap-связку и три команды. Выбор в инспекторе сохранится.

## Validation

Проверить парсер, архитектуру, ссылку на кнопку. В Godot проверить переключение,
отсутствие выстрела при клике и скрытие кнопки с другими видами оружия.

## Approval

Запрос владельца 29.09.2026: добавить кнопку переключения при выбранном гранатомёте
для тестирования двух взрывов; новые команды нужны для этой кнопки.
