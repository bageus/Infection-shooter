# ADR-0018: Звуковые эффекты

- Status: accepted
- Date: 2026-10-04
- Owner: bageus
- Modules: core.audio (новый), features.combat, features.infected, features.player, features.character_animation, features.pickups, presentation.office_floor, bootstrap.app

## Контекст

Владелец попросил найти и добавить звуки: выстрелы (пистолет, дробовик, узи,
винтовка, автомат, гранатомёт), взрывы гранаты и огнетушителя, перезарядку,
аптечку/антидот, подбор оружия/ключа/ДНК, шаги, гильзы, двери и лифт, стекло,
попадания по металлу/дереву/бумаге/электронике/стене/небьющемуся стеклу, урон
и отстрел конечностей врагов, падение предметов, бег и атаки разных врагов.
Звуки должны быть обработаны, чтобы звучать естественно.

## Решение

- **Источники** (только свободные лицензии, клонирование публичных репозиториев):
  [CDDA-Soundpacks](https://github.com/Fris0uman/CDDA-Soundpacks) (CC0 / CC-BY,
  авторы по строкам credits.md) и [Red Eclipse sounds](https://github.com/redeclipse/sounds)
  (CC-BY-SA 4.0). Часть звуков синтезирована (звон ключей, попадание по бумаге,
  гонг и мотор лифта). Полная атрибуция каждого файла — `assets/audio/CREDITS.md`;
  при распространении сборки её нужно сохранять, а производные от Red Eclipse
  файлы остаются под CC-BY-SA 4.0.
- **Обработка** (`tools/build_sounds.py`, воспроизводимо): моно 44.1 кГц,
  обрезка тишины (у выстрелов без задержки атаки), DC/high-pass, noise gate,
  экспоненциальное затухание хвоста, наклонный EQ, наслоение слоёв (выстрел +
  механика, взрыв + обломки), варианты высоты, выравнивание громкости по
  категориям (RMS 50 мс), мягкий лимитер −1 dBFS, микро-фейды, Ogg Vorbis q5.
  194 файла, ~3 МБ, 60+ событий по 1–10 вариантов.
- **core.audio** (`public/sound_events.gd`, контракт `sound_events_v1`):
  `SFX.play(parent, event, position, volume_db, pitch)` создаёт
  самоудаляющийся AudioStreamPlayer3D на шине SFX; каталог EVENTS задаёт
  варианты, громкость, дальность, размер источника, разброс высоты и лимит
  одновременных голосов (общий лимит 48). В headless звук не запускается.
  Нет глобального состояния: голоса находятся группами сцены.
- **Микс**: `default_bus_layout.tres` — Master с HardLimiter, шина SFX с
  короткой реверберацией помещения и компрессором. Слушатель
  (AudioListener3D «Ears») стоит на высоте головы игрока, а не на камере.
- **Хуки**: оружие (выстрел, сухой щелчок, перезарядка с отменой, заряжание
  дробовика по патрону, гильзы по типу оружия), пули (звук по материалу
  попадания), граната и огнетушитель, двери (обычная/металлическая/стеклянная/
  лифт), разбивание стекла, падение физических предметов и обломков
  (`impact_sound_watcher.gd`), шаги игрока по фазе походки
  (`footstep` сигнал character_animation), враги (`infected_audio.gd`: шаги
  по типу, рык при беге, замах, удар/укус, попадание, отрыв части, смерть,
  удар Colossus, таран и призыв Horde), подбор предметов.
- «Винтовка» и «автомат» имеют готовые события (`rifle_fire`,
  `assault_rifle_fire`) и привязку по имени оружия RIFLE / ASSAULT RIFLE;
  в игре их пока нет.

## Последствия

- Новые наборы `run_sound_event_tests.gd` и `run_sound_hook_tests.gd` в CI.
- Громкости подбираются только в EVENTS; повторная генерация — запуск
  `tools/build_sounds.py` на клонах источников.
- Прослушивание в игре не выполнено (нет аудиоустройства) — приёмка по
  docs/SOUND_QA.md.
