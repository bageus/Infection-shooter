# ADR-0026: Изображения и состояния дисплеев

- Status: accepted
- Date: 2026-10-05
- Owners: presentation.office_floor — authored настройки и производное представление дисплея; bootstrap.app — UI и сохранение карт.
- Related modules: presentation.office_floor, bootstrap.app

## Context

Владелец добавил два атласа 4×2 и три GIF VECTRION и запросил изображения только на экранах, состояния on/off/auto, выбор static/dynamic, свечение спереди, различные картинки двойных мониторов и цельную картинку на соседних безрамочных ТВ. Исходные GLB объединяют дисплей, корпус и стойку; назначать текстуру всему материалу нельзя. GIF напрямую не являются runtime-текстурами Godot.

## Decision

Аддитивный public display_v1 у существующего environment_prop принимает {power, content, seed}. Настройки экспортируются для authored scene и сохраняются в optional `display` DTO. Seed определяет auto (50% включены), изображение и разные изображения двух экранов; его сохраняют, поэтому авто не мигает и не меняется при загрузке/undo. Телевизоры принудительно dynamic. Закрытый ноутбук исключён.

Отдельные локальные display_view, display_content и display_wall_layout владеют геометрией, материалами/кадрами и объединением панелей. Public display_wall инжектируется bootstrap world_bindings, никогда не ищется в SceneTree. Один mission-local tick считает три кадра; пересборка соседства ограничена 0.15 с и запускается только при изменении состава/трансформаций/настроек. Spotlight с полным конусом менее 180° освещает только переднюю полусферу. Короткое замыкание выключает экран и его свет, не изменяя authored настройки.

Геометрия экранов извлекается build_display_surfaces.py из лицевых плоских треугольников исходных GLB, с исходными SHA-256. Mesh не включает корпус/стойку и не участвует в collision. Исходные ТВ лежат в XZ; их visual поворачивается на +90° вокруг X, как требуется прежним wall-placement с +Z front. Остальные модели не поворачиваются.

GIF преобразуются build_display_atlases.py в lossless PNG атласы с кадром 320×180, gutters 1 px, максимум 3542×2002. Все интервалы GIF сохранены. В rotation исходный последний кадр повреждён: только его 50 мс занимают последний целый кадр. Исходники не переписываются.

Layout DTO v8 добавляет optional `display`; старые карты v6/v7 и записи без поля получают auto/static и случайный устойчивый seed. v7 зарезервирован для отдельного PR светильников. Существующие поля не переименовываются. Экранные настройки сохраняются в bake, named maps, snapshot, undo, duplicate и delete/restore.

## Alternatives considered

- Текстура на всей поверхности Intact: затрагивает корпус/клавиатуру, отклонено.
- GIF декодировать во время игры или добавлять плагин: лишняя зависимость и неподдерживаемый Web путь, отклонено.
- OmniLight: освещает сзади, отклонено.
- Изображение каждого ТВ отдельно: разрывает единую видеостену, отклонено.

## Consequences

Новые изображения повышают расход памяти: суммарно около 84 MiB decoded RGB/RGBA для пяти исходных/подготовленных атласов без mipmaps. Текстуры разделяются Godot resource cache; материалы локальны. Авто означает стабильный случайный выбор при создании, а не новый выбор каждый кадр. Панели объединяются при совпадении направления, масштаба и плоскости, соприкосновении краёв с допуском 2.5 см в координатах панели; удаление/перемещение разделяет стену. Выключенная часть стены остаётся чёрной.

Файлы environment_prop, planning_controls, planning_objects и planning_storage выше мягкого порога пересмотрены: в них остаются только integration/DTO hooks. Геометрия, UI дисплеев, анимация и группирование выделены по ответственности. Hard limits и направление зависимостей не меняются; исключений нет.

## Migration plan

1. Сохранить оригинальные ассеты, добавить воспроизводимые runtime PNG/timing и профили.
2. Объявить display_v1 в module.json, подключить компонент и mission-local registry.
3. Добавить optional DTO и UI без изменения прежних полей; проверить загрузку старых карт.
4. Проверить оба renderer и planner round trip, повреждение и lifecycle.

## Rollback plan

Откатить task-scoped commit. Старый код игнорирует optional display и сохраняет остальные поля v8 как прежде; backup карты не перезаписывать при возврате. Исходные GIF/PNG владельца сохранены.

## Validation

Project gates; headless import; дисплейные runtime и planner regressions; pixel checks Compatibility и Forward+; main smoke. Подробный маршрут: docs/DISPLAY_QA.md.

## Approval

Владелец явно запросил реализовать эти настройки, изображения, свечение и объединение экранов; затем загрузил ассеты и поручил «проверяй». Одобрение относится к узкому аддитивному display_v1/optional display DTO, необходимому для сохранения запрошенных настроек. Новые модули, зависимости, плагины и архитектурные исключения не вводятся.
