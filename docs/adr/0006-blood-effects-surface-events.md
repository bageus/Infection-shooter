# ADR-0006: Кровь через события врагов и привязанные следы

- Status: accepted
- Date: 2026-09-30
- Owners: bageus
- Related modules: features.infected, presentation.office_floor, bootstrap.app

## Context

Прежний эффект крови создавал множество SVG Decal прямо из feature врага и не работал в Compatibility. Владелец запросил пять категорий PNG, общий бюджет, поверхности и безопасные отложенные лужи.

## Decision

Infected сохраняет владение уроном, здоровьем, смертью и движением. Публичные сцены врагов публикуют typed факты projectile_blood, blood_wounded, wounded_moved, body_dragged, blood_death; параметры исключений — Array[RID], не ссылки на удаляемого врага. blood_drop_distance — конфигурация расстояния между событиями. Bootstrap связывает всех существующих и новых врагов с публичной сценой BloodEffects3D.

Presentation.office_floor владеет только визуальными следами. Публичная сцена v1 предоставляет splatter_hit, small_stain, drops_trail, smear_drag, death_pool, clear_marks, movement_spacing и diagnostics v1. Разделены библиотека PNG, поиск/проверка поверхностей, отрисовка одного следа и ограничение времени/количества. Следы живут в BloodMarks; RemoteTransform3D на поверхности передаёт её перемещение. Отложенные запросы содержат WeakRef поверхности и локальную позицию, но не узел врага.

Слой 8 (бит 128) отдельно маркирует physics-окружение и GeometryInstance3D-приёмники. Существующие биты сохраняются, actor-ветки не маркируются. Настройки рендеринга не меняются. При запуске diagnostics проверяет API через ClassDB именно запущенного движка и сохраняет его версию/renderer; локальная проверка 4.7.2 всё равно требует доступного бинарника. Фактический RenderingServer method выбирает Decal либо прозрачный QuadMesh. Mobile консервативно ограничивает число активных/исчезающих следов на одном collider шестью, что может раньше очищать кровь на больших объединённых поверхностях.

## Alternatives considered

- Новые Decal в feature врага отвергнуты: нет Compatibility, общего бюджета и корректного отделения presentation.
- Ссылки на врага внутри lambda/timer отвергнуты из-за прежних freed-capture ошибок.
- Изменение renderer и внедрение ragdoll/волочения отвергнуты: это отдельные игровые задачи.

## Consequences

Урон и смерти не меняются. Капли привязаны к реальному расстоянию, лужа запланирована однажды и сохраняет данные до удаления врага. API мазков обслуживает реальное внешнее перемещение мёртвого тела, но не вводит новую механику волочения или видимый ragdoll.

## Migration plan

Удалить старые SVG/воздушные mesh-эффекты из врага, добавить события и bootstrap-связку. PNG остаются исходными RGBA; кешируемые копии обрезают прозрачные поля и уменьшаются до 512px без изменения файлов. Форматы сохранений и боевые public-команды не меняются.

## Rollback plan

Отключить bootstrap-связку и удалить BloodEffects3D из сцены; вернуть старую отрисовку врага. ID врагов, здоровье и карты сохраняются.

## Validation

Проверить нормали и basis, пол/стену/наклон/платформу, исключение actors, восемь Mobile slots и общий бюджет, отложенную смерть после удаления врага. API сверяется с официальной документацией; локальный Godot 4.7.2 отсутствует, имеющийся 4.5.2 аварийно завершается. Не считать визуальную проверку успешной до запуска в рабочем редакторе.

## Approval

Прямой запрос владельца 30.09.2026: BloodEffects3D, методы пяти эффектов и подключение к существующим событиям без изменения урона.
