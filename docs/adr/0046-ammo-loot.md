# ADR-0046: Боеприпасы в луте

Status: accepted; Date: 2026-10-15; Owner: bageus, прямое подтверждение задачи2.

Общий вес патронов3 распределяется .75/.60/.60/.60/.15/.30 (pistol/uzi/shotgun/automate/sniper/minigun); аптечка1 и антидот.35 прежние. Шанс65% и один предмет на убийство прежние, все обычные виды врагов используют эти веса, призванные по-прежнему без лута. AUTO ящиков дополнительно сохраняет прежний DNA.2. Каталог SCENES единый в drop_table, loot_drop его использует. Добавлены три ID в существующую loot config форму; схема карты v8 прежняя. Старые readers неизвестные ID игнорируют. Существующие сцены дают30/8/100, общий ящик АК/M4 отдаёт30 первому принимающему оружию. Лечение не менялось.

Лимит40 учитывает живой временный дроп, пропускает уже queued-free и не удаляет авторский persistent loot: массовые убийства в одном кадре больше не выбирают многократно один уже удаляемый предмет. Альтернатива — увеличить общий объём лута — отвергнута владельцем. Откат revert PR, сохранения не переписываются. Новых владельцев/зависимостей/исключений нет. Проверки: planner_loot (реальный player и четыре оружия), enemy_loot (веса/лимит), pickup_floor, placed_ammo, обязательные валидаторы/import.
