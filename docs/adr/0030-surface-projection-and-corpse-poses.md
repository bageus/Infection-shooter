# ADR-0030: Декали по форме поверхностей и позы декораций

- Status: accepted
- Date: 2026-10-05
- Owners: владелец проекта; bootstrap composition
- Related modules: core.vfx, features.combat, features.infected, presentation.office_floor, bootstrap.app

## Context
Владелец уточнил требования: декаль должна учитывать форму стены/колонны/мебели и продолжаться на соседнем объекте; копоть не наносится на стекло. Прямоугольные QuadMesh выступают за края. Дуло может оказаться за тонкой преградой ещё до запуска пули. Нужны случайные позы размещаемых тел и частей, видимые параметры установленных ламп, единые предупреждения во вкладках и исправление показанных ошибок.

## Decision
core.vfx предоставляет stateless surface_stamp_v1: проекция UV и обрезка полигонов по ограниченному объёму на исходных треугольниках. features.combat владеет поиском физических принимающих объектов и существующими visual registrations; impact_projection_v1 возвращает геометрию/меши для максимум 12 получателей. Вызывающий код сохраняет владение временем жизни и бюджетом. Сплошные поверхности принимают копоть, стеклянные материалы и обратные стороны исключаются. Процедурный пол без отдельного MeshInstance использует подготовленную BoxShape-геометрию. Новых зависимостей или исключений нет.
Перед выстрелом проверяется отрезок от тела стрелка до дула; непроницаемая преграда получает попадание, пуля не появляется за ней. Баллистика и расход патронов сохраняются.
features.infected владеет authored-позой декорации: seed и выбранный вариант сохраняются через additive decor_pose_v1, optional поля существующего maps DTO v8. Позы создаются до отсечения частей и построения hitboxes. Bootstrap пробует место, выбирает безопасную лежачую либо пристенную сидячую/наклонённую позу и не меняет позу при каждом кадре preview. Части получают устойчивую случайную XYZ-ориентацию; их масштаб и физика прежние.
Bootstrap владеет единой системой уведомлений вкладок, отдельной от прокрутки наполнения. Постоянные подсказки и ошибки ввода/сохранения используют её. Параметры лампы группируются перед палитрой и автоматически прокручиваются в видимую область.

## Alternatives considered
Увеличивать/уменьшать плоский квадрат отклонено: форма мебели и соседние объекты остаются неверными. Только native Decal отклонено: Compatibility не поддерживает его. Глобальный сервис декалей отклонён: существующий mission-local injected pool достаточен. Перестроение позы каждый кадр отклонено: preview нестабилен, а сохранённая карта недетерминированна.

## Consequences
UV едины для одного наложения на соседние получатели; каждый фрагмент следует собственному мешу. Ограничения: 12 получателей и 4096 выходных треугольников на меш; поиск только при создании/изменении декали. Нет свободных прямоугольников в воздухе. Позы сохраняются как authored-данные; старые карты остаются читаемыми.

## Migration plan
Добавить версии публичных контрактов и manifests, optional decor-поля в DTO v8, задокументировать default для legacy. Сохранить пути public сцен. Повторить регрессии стрельбы/поверхностей/поз/Undo/карт и оба рендера.

## Rollback plan
Revert этого инкремента возвращает плоские декали и прежние позы; старый код игнорирует optional decor-поля. Слияния PR остаются.

## Validation
Торцы, колонны, соседние объекты и стекло; no-through-wall при дуле внутри/за стеной; кровь на столе/стуле; все установленные лампы; уведомления и поля управления без meta-ошибок; разные детерминированные позы и roundtrip сохранения. Полные gates, headless runtime и GPU Compatibility/Forward+; Windows/Web проверяются отдельно.

## Approval
Прямой запрос владельца в этом сообщении разрешает описанные изменения. Стоящее разрешение T002 позволяет сохранять проверенные изменения в main до MVP. Архитектурных исключений нет.
