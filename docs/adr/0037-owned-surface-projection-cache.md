# ADR-0037: Локальный кеш проекции следов

- Status: accepted
- Date: 2026-10-06
- Owners: features.combat — существующий пул эффектов миссии
- Related modules: core.vfx, features.combat

## Context
При каждом следе surface_stamp читает surface_get_arrays и перебирает всю поверхность. Владелец поручил последовательно реализовать предложенную оптимизацию surface_stamp, затем взрывов, крови, дверей и частей тел.

## Decision
Существующий stateless surface_stamp_v1 и его сигнатура сохранены. Аддитивный surface_stamp_cache_v1 предоставляет принадлежащий вызывающему коду RefCounted-объект с тем же build. Он хранит максимум 128 immutable снимков Mesh и локальные BVH. Mesh.changed инвалидирует снимок; индивидуальное вытеснение и уничтожение отключают наблюдателя с weak-ссылкой на владельца. Состояние миссии продолжает принадлежать features.combat/impact_effects. Новый адаптер core.vfx не содержит глобального состояния. Получатели, transforms, active materials и выходные меши не кешируются. Временные proxy пола используют исходный stateless путь.

## Alternatives considered
Глобальный static-кеш отклонён: нарушает владение и lifecycle. Кеш в metadata Mesh отклонён: изменяет общие authored-ресурсы. Полный перебор оставлен как совместимый эталон и fallback для временного proxy.

## Consequences
Повторный небольшой след проверяет пространственно отобранные треугольники в исходном порядке. Первый запрос строит индекс; память ограничена числом ресурсов, но зависит от сложности их геометрии. Консервативный локальный AABB допускает лишние кандидаты; исходная точная обрезка, normals, UV, offsets и лимит 4096 сохраняются.

## Migration plan
Объявить один новый контракт core.vfx, подключить instance к существующему пулу, сравнить массивы результата с v1. Зависимости, сцены, DTO v8 и остальные публичные контракты прежние. Архитектурных исключений нет.

## Rollback plan
Revert возвращает вызов stateless build; выходные ресурсы и сохранения совместимы.

## Validation
Сравнение полного и индексированного пути: transforms/negative scale, UV/normals, glass, замена Mesh, Mesh.changed, независимые кеши, освобождение и cap 128. Полный project gate и Godot CI, затем визуальная приёмка Windows/Web.

## Approval
Владелец разрешил реализацию предложенного локального кеширования запросом «приступай по порядку». Это разрешение действует только на описанный ограниченный адаптер; направления слоёв, владельцы игрового состояния и форматы не меняются.
