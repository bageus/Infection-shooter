# ADR-0022: Рост Horde, эскалация призыва и звуки интерфейса

- Status: accepted
- Date: 2026-10-05
- Owners: bageus
- Related modules: features.infected, core.audio, bootstrap.app

## Context

Владелец запросил ещё +30% размера Horde, призыв Hunger/Revenant/Brute по убыванию здоровья без ожидания гибели прошлой волны, удаление mutant_animated и отдельные звуки обычного меню, навыков и замка. Имя mutant_animated в запросе повторено; zombie_animated не удаляется без уточнения. Прежний призыв зависел от лимита шести живых обычных врагов.

## Decision

- Body Horde: 1.7 → 2.21 по XYZ. Капсула r=1.365, h=2.73 (исходная h=2 при r=1.05 фактически зажимается движком до 2.1). Body offset, референсные скорости анимации, авторские трупы/щупальце масштабированы согласованно. HP и скорость поведения прежние.
- Domain horde_summon.tier — правило без сцены: HP > 2/3 Hunger, 1/3 < HP <= 2/3 Revenant, HP <= 1/3 Brute. Пороги — исходное решение реализации, владелец не задал числа. Выбор по здоровью в момент выпуска волны, а не начала анимации. Три экземпляра каждые 12 с (первый cooldown 5 с); прежние условия дистанции/тарана сохранены. Лимита живых призванных нет; отмена при смерти сохранена. Проверяется полная капсула вида против стен/предметов, высота размещения относительно основания капсулы Horde; призванные получают world/target и маркер без лута до ready. Pulse привязан к основанию выросшего Horde.
- Поля summon_scene (Hunger), summon_revenant_scene, summon_brute_scene — авторская конфигурация существующей публичной сцены. Новых межмодульных команд и владельцев состояния нет.
- mutant_animated.glb, import и Mutant_anims.res удалены. Совместимые публичные сцены мутанта и декора используют Brute_rig; пути старых JSON прежние, боевые значения старой сцены сохранены. В новой палитре нет дублирующего мутанта/декора. Генератор больше не требует старую модель.
- Совместимое дополнение sound_events_v1: play_ui(parent: Node, event: StringName) -> AudioStreamPlayer. Пять коротких PCM cues на сухой шине UI → Master, без 3D затухания/реверберации. Голоса принадлежат UI, работают при паузе и освобождаются по окончании/выходу; собственный бюджет 8, максимум 3 одного события. Без новых глобальных счётчиков. Bootstrap зависимость core.audio явно добавлена в manifest до использования. Изолированный UI integration test использует публичный infection_runtime, поэтому test dependency features.infection также явно объявлена; рабочая композиция по-прежнему получает runtime от игрока.
- Hover обычных меню/диалогов — menu_hover; навыки (включая learned/disabled circles с tooltip) и замки — mutation_hover; покупка — mutation_click; фактическая фиксация/снятие — mutation_lock/unlock. PCM снятия точно обратен PCM фиксации. Звук создаётся под устойчивым слоем, не под удаляемой при refresh кнопкой. Параметры sound/volume применяются через прежние настройки Master; обычное меню дополнительно проверяет свои preferences.
- Генерация assets/audio/ui/*.tres воспроизводима tools/build_ui_sounds.py, только stdlib; оригинальный синтез CC0, без новых dependencies. Существующий menu click остаётся прежним.

## Alternatives considered

- Поднять alive cap: после накопления снова блокирует волны, не соответствует запросу.
- Удалить старые публичные пути мутанта: ломает карты, отклонено.
- Новый аудиосинглтон или 3D звук из меню: скрывает владение/зависит от слушателя и паузы, отклонено.
- Новые внешние записи/библиотеки: несколько коротких cues обеспечены синтезом, зависимости не нужны.

## Consequences

Постепенно растёт число врагов при живом Horde; конечный cooldown и count остаются авторскими. Нагрузку в полностью заполненной локации и субъективное звучание необходимо проверить отдельно. Старые JSON не переписываются, DTO v5 прежний. Единственный дополненный межмодульный API — core.audio, остальное локальная конфигурация/подключение.

mutation_tree_ui уже выше мягкого лимита: сохраняется одна ответственность представления дерева; добавлены только три локальных обработчика звука/покупки/замка. Сложная новая система не требуется. build_enemy_rigs выше мягкого лимита: удалены только параметры старого ассета, обязанности генератора прежние. Hard-limit exceptions не добавлены.

## Migration plan

Автоматической конвертации нет: старые scene paths продолжают загружаться с новым визуалом. Новый UI API дополнен, прежний positional play неизменен. Отсутствующие старые GLB не используются генератором и сценами.

## Rollback plan

Revert коммита возвращает старый модельный ресурс/анимации, размеры и cap. Пользовательские карты не затронуты. Отдельно UI отключается прежним Sound или volume=0; численные громкости находятся в UI_EVENTS.

## Validation

run_horde_escalation_tests: границы HP, реальные четыре волны/12 живых, виды/дистанционные команды, одинаковая высота, блокирующая геометрия, смерть, старый map scene path. run_ui_sound_tests: меню/диалог, mute preference, реальная покупка/refresh/lock/unlock при паузе, отличие cues и точный reverse PCM, владельцы/освобождение. run_sound_event_tests: длительности, неизвестные события, лимиты UI. Все runtime-наборы и обязательные gates, импорт и CI; визуал/прослушивание — docs/SOUND_QA.md.

## Approval

Прямое сообщение владельца 05.10.2026 разрешает перечисленные изменения. Запись в main разрешена существующим рабочим соглашением; новых архитектурных исключений нет.
