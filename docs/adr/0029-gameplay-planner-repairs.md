# ADR-0029: Общая текстурная кровь, прицеливание и размещение

- Status: accepted
- Date: 2026-10-05
- Owners: владелец проекта; bootstrap composition
- Related modules: features.player, features.combat, features.infected, presentation.office_floor, bootstrap.app, core.audio

## Context
Владелец сообщил о висящих декалях стекла, устаревших моделях зомби, недостатке крови при разрыве, неправильной высоте и настенном креплении моделей, обрезанном интерфейсе, общей громкости музыки/эффектов и несогласованном прицеле. PR #25 и #26 интегрированы после проверки; #24 уже в main.

## Decision
Player владеет фактами урона и движения раненого: additive blood_events_v1 совместим с infected. Bootstrap подключает их к существующему office-floor renderer. Новых зависимостей gameplay от presentation нет. Ожидающие факты обрабатываются при game-over pause, время жизни пятен остаётся паузируемым. Разрыв порождает ограниченные текстурные брызги на полу и ближайших стенах.
Public combat contract добавляет aim_at(target) для согласования игрового и авторского дула. Обычный выстрел учитывает точную трёхмерную цель без ограничения высоты; проверка ствола ловит близкие предметы. Гранатомёт использует одну баллистическую формулу для скорости и ориентации дула. Optional casing size multiplier равен 0.7 только для гранатомёта.
Private interface_v1 получает effects_volume/music_volume с default 1: SFX+UI и Music независимо под существующим Master. DTO карт v8 и баланс прежние. Старые ресурсы/генерация Zombie удалены; прежние public пути сцен читают текущую модель Hunger для совместимости карт. Дубликаты палитры удалены. Размещение учитывает масштабированные границы модели и точный задний край на стене. Исключений владения состоянием нет.

## Alternatives considered
Отдельная процедурная кровь игрока дублирует renderer и сохраняет ошибку освобождённых объектов Array. Удаление public путей ломает старые карты. Выстрел вбок при неподвижном стволе противоречит контракту дула. Существующих injected collaborators достаточно без глобальных сервисов.

## Consequences
Кровь игрока использует общий бюджет текстур. Близкое препятствие получает попадание до выхода пули за ствол. Настенные модели привязываются к видимой геометрии. Оружие наклоняется к близкой цели. Громкость музыки сохраняется независимо; новая музыка не добавляется.

## Migration plan
Сначала интегрировать PR; добавить optional настройки/контракты/manifests. Заменить устаревшее изображение по прежним путям сцен, удалить ресурсы и генерацию. Сохранить совместимость DTO и секции private настроек. Пройти runtime, renderer и architecture проверки.

## Rollback plan
Revert инкремента оставляет слияния PR. Старый код игнорирует неизвестные optional ключи настроек. Восстановить удалённые ресурсы при отмене совместимых сцен.

## Validation
Урон/броня/смерть/следы, разрыв с кровью на стенах и полу, разрушение стекла настоящей пулей, масштабированный ковёр, контакт лого/TV со стеной, picker в маленьком окне, независимые audio buses, точная 3D цель и близкие препятствия, баллистика/гильзы. Runtime и project gates, затем оба GPU backend; Windows/Web проверяются вручную.

## Approval
Запрос владельца от 2026-10-05 разрешает эти изменения, удаление старых моделей и слияние всех активных PR в main. Working agreement разрешает публикацию согласованной работы T002 в main. Архитектурных исключений нет.
