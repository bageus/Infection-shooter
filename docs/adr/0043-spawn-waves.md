# ADR-0043: Волны спавна и точки-отверстия

- Status: accepted
- Date: 2026-10-14
- Owners: владелец проекта; features.spawning
- Related modules: features.spawning, features.infected, bootstrap.app

## Context
Уровень рассчитан примерно на 90 врагов одновременно. Расставлять всех заранее дорого для кадра, а зачистка части уровня не вызывает новых врагов. Владелец попросил точки спавна с настройкой количества, типа, интервала и правил, триггеры на врагах и общий потолок 90 живых врагов.

## Decision
1. Новый модуль `features.spawning` (слой features, зависит от `features.infected`). Публично: `public/spawn_point.tscn`, `public/spawn_config.gd`, `public/wave_director.gd`.
2. Точка спавна: узел `spawn_point.tscn` — процедурное отверстие в полу (рваный бетонный край, тёмный центр, обломки, арматура) и конфиг `{enemy, count, interval, rule, batch, trigger}`. Враги появляются на кольце вокруг отверстия в первом направлении, где луч не упирается в стену.
3. Правила: `stream` — по одному каждые `interval` сек; `burst` — пачка `batch` каждые `interval`; `refill` — по одному, пока живых своих меньше `batch`.
4. Триггеры: враг хранит в meta `spawn_triggers` список `planning_object_id` точек. Точка срабатывает один раз за миссию: `any` — первая смерть связанного врага, `all` — когда умерли все связанные. Недействительный (освобождённый) враг считается мёртвым. Точка без связанных врагов не срабатывает.
5. Очередь: `domain/wave_queue.gd` хранит сработавшие точки, остаток и таймер каждой. Живых врагов на уровне не больше `MAX_ALIVE = 90`; свободные слоты достаются точкам по очереди. Подсчёт идёт по группе `infected_alive` (её ведёт `features.infected`), поэтому врагов, расставленных заранее, и вызванных Ордой он учитывает так же.
6. `wave_director.gd` создаётся в `main.gd`, получает корень врагов и игрока. Заспавненный враг получает `set_target(player)` и meta `spawned_by`, `spawn_origin`. Планировщик при входе вызывает `disarm()` (заспавненные враги удаляются, очередь сбрасывается), при выходе `arm()`.
7. Сохранение карты: запись точки получает `spawn_point`, запись врага `spawn_triggers`; проверка карты отклоняет неверные типы; версия карты остаётся 8, поля необязательные.
8. Панель планировщика `planning_spawn_options.gd` стоит справа и не входит в палитру: она открывается на вкладке «Враги», при выборе точки и при выборе врага. Для врага это список точек с флажками, для точки — настройки волны. Связи рисуются линиями, пока выбран один из концов.

## Alternatives considered
- Сигнал смерти врага: потребовал бы менять `infected_capsule.gd`, который меняют соседние задачи. Опрос раз в 0,25 с дешевле по согласованию и достаточен.
- Потолок отдельно по зонам: у владельца потолок общий для уровня.

## Consequences
- Восприятие врагов (зрение, слух) делает другая задача; заспавненные враги пока получают цель на игрока, как и расставленные.
- Анимация вылезания из отверстия не сделана; враги появляются рядом с ним.
- Правка связей и настроек поддерживает отмену через `planning_edit_history.gd`.

## Validation
`run_wave_tests.gd` (конфиг, правила триггера, очередь, потолок, директор), `run_spawn_planner_tests.gd` (панель, связи, сохранение, отмена, запуск волны после выхода из планировщика), `validate_project.py`.
