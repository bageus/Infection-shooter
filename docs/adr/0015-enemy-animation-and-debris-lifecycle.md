# ADR-0015: Анимация врагов и жизненный цикл обломков

- Status: accepted
- Date: 2026-10-03
- Owner: bageus
- Modules: features.character_animation, features.infected, presentation.office_floor, bootstrap.app

## Контекст

Общий драйвер выбирал клип по подстроке имени, не зацикливал импортированные
клипы (GLB импортирует loop_mode=0 без суффикса `loop`), не имел порога Run,
атаки и смерти. Шесть новых врагов (hunger, revenant, brute, titan, colossus,
horde) — статические меши без скелета и клипов, каждый тяжёлый. Обломки
разрушаемых объектов не сталкивались со стенами, проходили сквозь пол,
не исчезали плавно, не наследовали движение, а осколки `physical_prop` не
имели коллизии.

## Решение

Драйвер character_animation получает совместимые public дополнения
`animation_events_v1`: `play_one_shot(state) -> float` (attack, death; смерть
финальна), `notify_hit()`, `set_active(bool)`, сигнал
`one_shot_finished(state)`. Старые экспорты и `animation_selection_v1` не
менялись. Если у визуала есть AnimationPlayer, используются клипы (loop
выставляется instance-owned копиям, attack чередует Left/Right, Run выбирается
по скорости погони). Если нет — тот же интерфейс обслуживает процедурный
backend (`procedural_pose.gd`, чистая математика позы вокруг ступней: наклон,
покачивание, замах/выпад, падение назад, вздрагивание). Когда придут
риггованные модели, клипы подхватятся автоматически.

features.infected наносит удар на кадре попадания (после замаха), проверяя
дальность в этот момент; смерть проигрывается до погружения трупа; далёкие
враги ставят анимацию на паузу. Геймплейные числа не менялись.

Для шести врагов создаются облегчённые derivative-меши и материалы
(`tools/build_enemy_game_models.gd`); канонические GLB не изменены.

presentation.office_floor: общий `debris_lifecycle.gd` (плавное уменьшение,
пыль, бюджет 6 облаков, процедурные осколки); обломки на слое 3 (значение 4),
маска 3, явные collision exceptions с игроком и заражёнными, бюджет 40 штук,
наследование скорости разрушенного тела, CCD только для mass < 4,
реакция-вздрагивание при неразрушающем попадании.

## Альтернативы

- Ждать риггованные модели: оставляет врагов статичными.
- Отдельный AnimationTree: тяжелее и избыточен для двух one-shot состояний.
- Делать обломки слоем 1: персонажи получали бы столкновения с ними.

## Миграция и откат

Новых save/network DTO нет; модули и рёбра зависимостей прежние. Откат —
revert коммита; канонические модели не менялись.

## Риски и проверка

Процедурная анимация — временная замена скелетной. Визуальная приёмка
(ADR-0014) остаётся открытой. Тесты: run_enemy_animation_tests.gd,
run_debris_tests.gd (добавлены в CI), прежние 13 наборов.
