# ADR-0060: Настройка игровой камеры через Alt

- Status: accepted
- Date: 2026-10-19
- Owner: bageus, прямой запрос управления камерой и запоминания углов
- Modules: features.player, bootstrap.app

## Решение

Player сохраняет владение ракурсом. Additive camera_adjustment_v1 на публичном
корне: get_camera_adjustment / set_camera_adjustment, словарь yaw/pitch в градусах,
distance в метрах. Private helper обрабатывает Alt+ЛКМ с чувствительностью
планировщика 0.008 рад/пиксель, наклон -80..80°. Камера вращается вокруг игрока;
zoom/recoil/weapon bonus продолжают работать. Alt блокирует обычную стрельбу.
Bootstrap получает публичный snapshot и сохраняет отдельный локальный
user://gameplay_camera.cfg, camera_v1.version=1/view. Показывает RU/EN параметры
под радаром только при Alt в неприостановленной игре. Запись после настройки,
не на каждом кадре; при уничтожении dirty preference также записывается.

## Альтернативы

Вращать камеру на месте как свободную камеру планировщика: игрок уйдёт из кадра.
Сохранять transform карты: ракурс пользователя зависит от конкретной миссии.
Редактировать большой player root: новая ответственность раздувает адаптер.

## Совместимость и откат

Без файла прежний ракурс. Неверный тип, отсутствующие поля и NaN/Inf игнорируются;
конечные числа ограничиваются. Карты/gameplay saves прежние, модульные рёбра,
владельцы и policy не меняются. Откат удаляет helper/wiring/API; отдельный cfg
старый код игнорирует. Новых dependencies/plugins/Autoload нет.

## Проверки

Camera suite: round-trip, bounds, malformed preferences, удержание focus,
совместимость normal update и weapon zoom/recoil. Общие architecture/project gates.
Ручная проверка расположения панели и удобства управления требуется на native/Web.

## Одобрение

Прямой запрос владельца разрешает управление, сохранение углов и readout.
Публичный additive контракт обеспечивает это без доступа UI к внутренностям player.
