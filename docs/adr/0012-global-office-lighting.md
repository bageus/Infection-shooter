# ADR-0012: Общий верхний свет и разрешение локальных ламп

- Status: accepted
- Date: 2026-09-30
- Owners: bageus
- Related modules: bootstrap.app, presentation.office_floor

## Context

Владелец прямо запросил вместо множества световых пятен один основной свет этажа, слабый ambient и возможность одним переключателем вернуть прежние лампы без изменения карт. Стример вызывает set_runtime_light_active(true), а прежняя реализация лампы игнорировала аргумент.

## Decision

GlobalOverheadLight — прямой ребёнок Main, вне CameraRig, PlanningObjects и Structure. PlanningLighting владеет экспортируемым local_lights_enabled=false и настройками ambient preview. Bootstrap применяет разрешение через существующую публичную сцену props/planner_light.tscn к группе planner_lights, включая поздно загруженные узлы; подписка node_added отключается при выходе из дерева. Office_floor не ищет контроллер или глобальное состояние.

Совместимое дополнение публичного API сцены v1: set_local_lighting_enabled(bool) -> void. Лампа владеет полученным разрешением, собственной runtime-активностью и фазой мерцания. Источник активен только при обоих разрешениях; set_runtime_light_active(bool) теперь соблюдает аргумент. Выключение скрывает Light3D, обнуляет только производную энергию и останавливает обработку кадров. Авторская энергия, параметры и shadow_enabled сохраняются; включение возобновляет прежнюю фазу. Постоянные лампы также не нуждаются в _process.

Ambient preview по-прежнему изменяет runtime-копию Environment и сохраняет все три ambient-поля. Общий directional остаётся неизменным в игровом и редакторском режимах; дополнительное заполнение редактора включается только явным выбором.

## Alternatives considered

- Удалить лампы или записать нулевые энергии в карты: разрушает авторские настройки, отклонено.
- Синглтон с общим флагом, поиск сервиса из лампы: нарушает границы владения, отклонено.
- Переиспользовать runtime-флаг для общего запрета: стример вновь включит лампы, отклонено.
- Один участок теней: дешевле, но качество при зуме не проверено; оставлен для визуального A/B. Стартовый вариант — два участка, 2048 px, 64 м, фильтрация Soft Low без PCSS.

## Consequences

Публичный контракт дополнен совместимо; зависимости и DTO карты v5 прежние. Старые карты не требуют миграции. Общая настройка принадлежит композиции приложения, не пользовательской карте. Один базовый источник с тенями; источники боевых эффектов вне области изменений.

## Migration plan

Ранее размещённые лампы по умолчанию выключены, но сохраняются как authored-объекты. При включении общего флага получают исходную формулу authored × multiplier × flicker. Пользовательские JSON не переписываются.

## Rollback plan

Отключить GlobalOverheadLight.visible и включить PlanningLighting.local_lights_enabled (Inspector или флажок «Локальные лампы»). Ambient отключается отдельно energy=0. Коэффициент лампы можно независимо вернуть к 1.0. Полный откат — revert без миграции карт.

## Validation

run_global_lighting_tests.gd: фактический -Z, дальность теней по лучам камеры, общий запрет и поздние узлы, четыре режима ламп, сохранение фаз, пять циклов выключения/включения, пять round-trip старой карты при выключенных лампах, переходы планировщика, вращение камеры, смена чанка и перезапуск. run_lighting_tests.gd сохраняет проверки ambient и авторских энергий. Подробности и открытая визуальная приёмка — docs/LIGHTING_QA.md.

## Approval

Прямой запрос владельца 30.09.2026 разрешает эту схему, общий флаг и запись непосредственно в main. Новых архитектурных исключений нет.
