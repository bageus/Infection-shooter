# ADR-0048: Музыка меню, интенсивность боя и группы голосов заражённых

- Status: accepted
- Date: 2026-10-15
- Owners: bageus
- Related modules: bootstrap.app, core.audio, features.infected, presentation.office_floor

## Context

Владелец предоставил 17 WAV и запросил их конвертацию без удаления оригиналов,
музыку главного меню/паузы, спокойные и боевую музыкальные петли, финальный boom,
локальный шум серверов и расширяемые группы голосов по виду и действию.

## Decision

Сохраняются существующие владельцы и направления зависимостей:

- bootstrap: private menu_music принадлежит MenuScreen и работает в паузе;
  private mission_music принадлежит main и приостанавливается вместе с миссией.
  Нет Autoload, сервисного поиска или нового межмодульного API.
- Главное меню запускает main_menu через 1 с после появления; refresh и диалоги
  не перезапускают запись. Меню внутри игры использует menu_from_game сразу,
  включая экран завершения/поражения. Скрытие экрана останавливает его звук.
- Music → Master для миссии, новая сухая MenuMusic → Master для меню.
  interface_v1 аддитивно получает menu_music=true и menu_music_volume=1.0.
  Старые настройки сохраняют defaults; игровой music_volume независим.
- Четырежды в секунду bootstrap читает существующие infected_alive/is_alerted.
  Больше трёх агрессивных врагов — Tower Hunt с переходом 2 с. До трёх включительно
  на протяжении 3 с — затухание 2 с, затем однократный cinematic boom и спокойная
  музыка. Три секунды и два секунды — выбранные параметры реализации против
  дребезга порога, не изменение агрессии врагов. Новый бой отменяет окончание/boom.
  Первый спокойный трек выбирается случайно, следующие чередуются.
- Office-floor: один AudioStreamPlayer3D на серверный шкаф, без callback на кадр.
  SFX, inverse-distance, unit_size=1м, max_distance=4м, источник на высоте1м.
  За пределами4м не слышно; у границы слабый звук, ближе громче. Разрушение и
  освобождение шкафа останавливают петлю; обычное неповреждающее попадание — нет.
- Infected: private enemy_voice_profile задаёт группы альтернатив и вероятность
  голоса. Частота/занятость и лимит SFX ограничивают речь, один текущий голос на
  экземпляр. Новых искусственных вариаций записей нет. Существующий tick перенесён
  до ветки unaware, поэтому idle/wander слышны, не инициируя агрессию.
  Agonize запускает соответствующий голос при успешном старте анимации;
  BiteLoop получает повтор жевания2.4–3.2с после завершения BiteDown. Подъём,
  переход к погоне, потеря ноги и смерть прекращают жевание.
- Найдена и исправлена ошибка конфигурации: в семи сценах custom audio exports
  стояли до script и игнорировались Godot. Переставлены после script, значения
  не изменены; виды теперь применяют авторские голоса/шаги/pitch.

Конвертированные OGG остаются рядом с WAV. В sfx/<group>/ лежат сгруппированные
копии для прежнего sound_events_v1. 48kHz Vorbis q5, музыка stereo, источники3D
mono. Хвост pause обрезан на1с, server fan на0.3с; после обрезки петля сведена
перекрытием80мс (итог58.92с/2.62с). Точный отчёт added_audio_processing.json.
Файл генерируется вне проекта, длительность проверяется ffprobe до атомарного
переименования, чтобы Godot не импортировал незавершённый поток.

## Alternatives considered

- Аудиосинглтон отклонён: локальный жизненный цикл сцен уже задаёт нужное владение.
- Подсчёт всех живых врагов отклонён: не соответствует запросу об агрессии.
- Отдельные callbacks на каждом сервере отклонены: затухание обеспечивает движок.
- Синтетические pitch-варианты как новые файлы отклонены: новые записи владелец
  добавит сам; реальное разнообразие отражается числом файлов.

## Consequences

### Positive

Оригиналы сохранены; новые группы и точные конечные комбинации учитываются в
автоматически обновляемом docs/ENEMY_AUDIO_GROUPS.md. Настройки меню доступны RU/EN.

### Negative

Сгруппированные OGG голосов дублируют конвертированные оригиналы (~210КБ), что
сохраняет существующий API и возможность владельцу убрать исходную папку позже.

### Risks and mitigations

Headless проверяет выбор, lifecycle, loop metadata и переходы, но не субъективную
громкость или слышимый музыкальный стык. Приёмка Windows/Web требует прослушивания.
В текущей модели CHASE сам не заканчивается при потере видимости; музыка читает
готовый public is_alerted, не меняя AI.

## Migration plan

1. Импортировать новые OGG и шину MenuMusic.
2. Старый interface_v1 загрузится с defaults двух добавленных ключей.
3. Сохранения карт/кампании и сетевые DTO прежние; WAV/import оригиналов сохранены.

## Rollback plan

Revert возвращает прежнюю аудиокомпозицию. Дополнительные ключи interface_v1
безопасно игнорируются старой версией. Авторские WAV и карты не переписывались.

## Validation

run_adaptive_audio_tests, run_enemy_voice_tests, run_server_audio_tests,
существующие sound_event, menu/settings, ui_sound, hunger_behaviour, perception,
idle_lod, horde_escalation и destruction_sound. validate_project, paths/imports,
headless editor, report --check. Итоговые результаты — docs/qa/adaptive_audio.md.

## Approval

Прямой запрос bageus от15.10.2026 разрешает указанные настройки, музыку, группы,
конвертацию и размещение файлов. Новых архитектурных исключений нет. Новые ключи
являются запрошенным дополнением локальных настроек, не форматом игровой кампании.

## Проверка headless lifecycle

Headless следует существующему SFX: реальные OGG декодеры не запускаются.
Bootstrap сохраняет часы/состояния/переходы; Timer завершает silent boom через
длительность записи, active отражает жизненный цикл меню. Native/Web playback
сохраняется. _exit_tree останавливает clocks/players. Это устраняет воспроизведённый
headless audio-mixer race при мгновенном выходе, без подавления ERROR.
Отдельный shutdown regression и native audio lifecycle в обоих renderer jobs
проверяют обе ветки. Новых публичных контрактов/owners/исключений нет.


## Дополнение: обновление записей 15.10.2026

Прямой запрос владельца заменяет сохранение WAV: 30 новых файлов конвертируются
в mono Ogg Vorbis q5/48kHz, затем удаляются после decode/hash/duration проверки.
Шесть исходных WAV музыки удаляются при наличии декодируемых готовых OGG;
музыкальные OGG не перекодируются. Квитанция audio_refresh_processing.json
содержит исходные пути, SHA256 и выходные параметры; источники доступны в Git 0e154b73.

Видовые death/idle/attack используют тот же профиль. Остаток roar_heavy_4
переименован в colossus_voice_1 и доступен как обычная речь Colossus,
не как общий клич тяжёлых. Удалённые scream_zombie больше не выбираются.
При обнаружении остаётся прежняя механика клича/слышимости, звук берётся
из оставшейся группы своего вида (Hunger — hunger_alert).

Аддитивный факт skill_cooldown_finished(skill_id: String) принадлежит
features.infection. Он излучается при positive→zero переходе активного
изученного навыка; естественный тик и ускорение используют один код.
Player audio подписывается на этот факт. Начальное zero и повторные
тики молчат; забытые/неактивные навыки и defeated runtime молчат.
Публичная сигнатура команды reduce_skill_cooldowns и значения таймеров прежние.
Новых dependencies, owners, DTO, Autoload и исключений policy нет.

Откат: revert инкремента вместе с восстановлением удалённых источников из Git.
Проверки и ограничения — docs/qa/audio_refresh.md.


## 20.10.2026 — Hold / Threat / Hunt, по прямому запросу владельца

Bootstrap остаётся владельцем музыки. Scene-local mission_music выбирает calm/threat/hunt; private music_crossfade удерживает не более3голосов, интерполирует мощность из текущих gains за4с и не обрывает прерванный fade. Threat стартует после подтверждённого projectile_blood заражённого (не попадания в игрока), Hunt — при >10агрессорах, <10 возвращаетThreat, ровно10 сохраняет режим; после3с без боя спокойный трек. Продолжение боя послеHunt использует loop-bodyThreat, не вступление.

Одноразовый completion_music создаётся composition root под SceneTree.root при успехе. Его точная ссылка передаётся loader/front_end, без Autoload/глобального состояния/поиска сервиса; проигрыватель не переподвешивается и не перезапускается при освобождении миссии. Меню/долгая загрузка повторяют Hold с4с перекрытием, при выходе в главное меню доигрывает текущая56с запись и только затем включается main_menu. Ошибка загрузки передаёт тот же голос в main, отмена/закрытие уничтожает его. После готовности миссии Hold затухает вместе с началомcalm. Шины MenuMusic/Music и настройки прежние.

Hold56с подтверждён владельцем. Stereo48kHz Vorbisq5; все WAV удаляются лишь после успешной decode/hash/duration проверки всех выходов. Threat loop_offset30.08с после80мс склейки с участком30.00..30.08; первые30с проигрываются только при новом бою. Server Oper active вырезает20с спереди и10с сзади, seam80мс; исходный OGG сохраняется как авторский источник. Seamless остаётся файлом, исключён только из runtime playlist. Receipt mission_music_processing.json. Карты, gameplay/сохранения и внешние public contracts прежние. Нового dependency/Autoload/исключения policy нет.

Rollback: revert PR восстанавливает прежние wrappers и WAV из его parent. Подтверждённое поведение требует передачи только музыки, не хранения gameplay между сценами. На standalone-прототипе без следующей карты Continue использует существующий маршрут рестарта; цепочка карт выбирает слот1 следующего уровня.
