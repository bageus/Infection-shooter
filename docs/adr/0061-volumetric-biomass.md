# ADR-0061: Объёмная биомасса с автоматической стыковкой

- Status: accepted
- Date: 2026-10-20
- Owner: bageus, прямой запрос: кровавая биомасса из меню в игре, куски стыкуются в одно целое
- Modules: presentation.office_floor, bootstrap.app

## Решение

Биомасса — это blood decal (planner_decor_v2) с texture id `biomass_01..06`; сохранение,
undo, пробы поверхности пол/стена/объект и DTO v8 не меняются. Шесть ячеек из карт материала
(basecolor с альфой, нормаль, высота) собраны в два атласа с зазором 16 px:
`assets/biomass/biomass_albedo.png` (RGBA) и `biomass_relief.png` (R,G нормаль, B высота).
Кусок рисует `biomass_surface.gdshader`: вершины сетки поднимаются на высоту рельефа
(до 5 см на 1 м), нормаль берётся из рельефа. Работает в Forward+ и в Compatibility.

Автостыковка (`biomass_fit.gd`, дочерний узел каждого куска): куски одного родителя на одной
плоскости (нормаль ≥0.97, смещение ≤4 см, одинаковый якорь) и с зазором ≤12 см
объединяются в группу. Первый кусок группы рисует всю группу как одну массу,
остальные скрываются. `biomass_fusion.gd` (чистая работа с изображениями, в рабочем
потоке) объединяет высоты гладким максимумом, закрывает малые щели размытым полем
занятости, соединяет близкие, но не касающиеся массы короткой жилой и пересчитывает нормаль
по итоговой высоте, поэтому шва нет. Пока кусок двигают, он показывает собственный рельеф;
группа пересобирается через 0.35 с покоя. Удаление или перенос куска возвращает остальные.

## Альтернативы

Отдельная сцена или DTO для биомассы: дублирует blood decal и миграции карт.
SDF/метаболы в шейдере: нужен renderer-специфичный код, не работает в web.
Запекание на GPU через SubViewport: не проверяется headless-тестами.

## Последствия

Старые карты не затронуты. Объединение стоит около 1 с на группу в рабочем потоке,
память до 900x900 px RGBA+RGB на группу. Контракт biomass_decor_v1 в module.json.
