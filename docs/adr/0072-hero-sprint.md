# ADR-0072: спринт героя с оружием в руках, шаг правой ноги, звук магазина

Статус: принято поручением владельца 25.11.2026.

## Решение

- Спринт (`player_sprint.gd`, `is_sprinting()`): удержание «Бег» при движении. Курсор и прицел снайперки скрыты, выстрел не срабатывает,
  тело смотрит по ходу бега (без поправки на ствол), скорость `sprint_speed`. С миниганом спринта нет: игрок не ускоряется. Перекат,
  потеря управления и отпускание клавиши возвращают обычную стойку и курсор.
- Клипы `Sprint_<оружие>` (`tools/build_hero_clips.gd`, в `hero_extra_clips.res`): `Standard Run` для пистолета и узи (оружие в правой
  руке, левая рука машет, ствол смотрит вперёд на 60 % от замаха руки), `Rifle Run (1)` для дробовика, гранатомёта, АК, М4 и снайперки
  (оружие сажается обоими хватами на обе руки в каждом кадре, пальцы хвата, рукав и видимость оружия берутся из `Idle_<оружие>`).
  Горизонтальный ход таза из клипов убран. Темп `ref_speed` 4,8 (около 1,7x при 8,1 м/с). `Running Backward` и `Rifle Run To Stop` не использованы.
- Правая стопа: циклы `Run_Forward*`/`Run_Backward*` ставят правую стопу носком наружу сильнее левой, `player_run_feet.gd` доворачивает её на 25°.
- Перезарядка пистолета и узи: `*_reload` (магазин вынут) и `*_reload_in` (то же, записанное задом наперёд) на 50 % перезарядки.
- Перекат: рука держит хват оружия ещё 0,3 с после переката, пока базовый клип перетекает из рук переката (двуручная стойка), иначе руки на миг показывали её.

Владельцы и DTO прежние. Тест `run_sprint_tests.gd`, снимки `/mnt/project-files/sprint_review/`.
