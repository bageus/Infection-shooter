# Анимации врагов и походка игрока: QA

## Что сделано (ADR-0016)
| Модель | Клипы | Особое |
|---|---|---|
| Zombie, Mutant | новые Idle/Walk/Run/AttackL/R/Death поверх их скелетов | бег с вытянутыми руками |
| Hunger, Revenant, Brute, Titan | авто-риг 22 кости + те же клипы | тяжёлые — медленнее, шире |
| Colossus | авто-риг + Slam | волна 6 м: урон, разрушение, отброс |
| Horde | ядро + 8 щупалец: Idle/Walk/Run(таран)/Summon/Death | без удара; таран; призыв 3 зомби |
| Игрок | авторский верх + процедурные ноги | шаг синхронизирован со скоростью |

## Проверено автоматически
- run_enemy_animation_tests: у всех клипы; Run тянет обе руки вперёд и чередует
  ноги; Walk шагает каждой ногой; AttackLeft/Right поднимают руку выше головы и
  бьют вперёд на кадре удара; Death лёжа; Walk/Run выбираются по скорости и
  идут с масштабом 1.0; враг вдалеке идёт шагом, вблизи бежит; волна Colossus
  ломает объект один раз, ранит игрока, отбрасывает ящик и щадит союзников;
  таран Horde разгоняется >7 м/с и бьёт один раз; призыв создаёт 3 зомби.
- run_gait_tests: обе ноги делают полные шаги поочерёдно, в покое ноги
  отдаются idle, страйф — диагональные шаги.
- Кадры рендера (Mesa llvmpipe) просмотрены для всех моделей.

## Визуальная проверка в игре
1. Поставить каждого врага в планировщике на 15–20 м: идёт шагом, на ~9 м
   переходит на бег с вытянутыми руками.
2. Подпустить: замах над головой, удар; урон приходит в момент удара.
3. Colossus: поднимает руки и бьёт по полу; кольцо ломает мебель вокруг.
4. Horde: ползёт, замирает, таранит; раз в ~12 с вздувается и вызывает зомби.
5. Игрок: ходьба/спринт/страйф/назад — ноги чередуются, не скользят.

## Риски
Темп stalk/charge, волна и таран/призыв меняют баланс (числа — заглушки).
Веса авто-рига — без художника: возможны мелкие растяжения в подмышках/паху.
Пересборка: `godot --headless --path . --script res://tools/build_enemy_rigs.gd`.
