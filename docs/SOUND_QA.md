# Приёмка звука (ADR-0018)

Проверять в Godot 4.7.2 в наушниках и на колонках.

- [ ] Выстрелы: пистолет, узи, дробовик, гранатомёт — без задержки, без щелчков в конце, громкость сопоставима.
- [ ] Сухой щелчок при пустом магазине; перезарядка звучит и обрывается при смене оружия.
- [ ] Дробовик: щелчок на каждый патрон.
- [ ] Гильзы: звон латуни / пластика дроби / тяжёлые у гранатомёта, не забивают выстрелы.
- [ ] Попадания: металл, дерево, бумага, электроника, стена, стекло (небьющееся) различимы.
- [ ] Разбивание стекла (окна, перегородки, предметы).
- [ ] Взрыв гранаты и огнетушителя, слышны на расстоянии.
- [ ] Двери: обычная, металлическая (ключ), стеклянная, лифт (гонг + мотор).
- [ ] Шаги игрока совпадают с постановкой ног при ходьбе и беге.
- [ ] Враги: шаги лёгкие/тяжёлые/Horde, рык при беге, замах и удар, попадания, отстрел частей, смерть, падение частей.
- [ ] Colossus: удар по полу; Horde: таран и призыв.
- [ ] Подбор: оружие, патроны, аптечка (+ применение), антидот, ключ, ДНК.
- [ ] Падение предметов не «стрекочет» при скольжении/покое.
- [ ] Нет перегруза при большой толпе (лимит голосов).

Подстройка громкости — `game/core/audio/public/sound_events.gd`, словарь EVENTS.

## Меню и мутации (ADR-0022)

- [ ] Главный экран, пауза, поражение, завершение и диалоги: одно короткое наведение на пункт, disabled пункт молчит; нет стрекота без движения мыши.
- [ ] Навык: отдельный hover, включая learned/недоступный круг с tooltip; click покупки не обрывается при перестроении дерева.
- [ ] Замок: закрепление — восходящий короткий cue, снятие — обратный; отказ операции не подтверждается звуком.
- [ ] Всё слышно при паузе, в наушниках/колонках и Web после первого пользовательского взаимодействия. UI без комнатной реверберации, независимо от камеры и удалённости персонажа.
- [ ] Sound=false и volume=0 выключают UI; после включения звук возвращается. Быстрое наведение/закрытие не оставляет голосов.

UI громкости: UI_EVENTS в sound_events.gd. Воспроизводимый синтез: python tools/build_ui_sounds.py (CC0). Headless проверяет сигналы, PCM и жизненный цикл; субъективное прослушивание не выполнено.

## Horde

- [ ] Body 2.21, трупы/щупальце того же размера: ноги на полу, движения/отстрел частей корректны.
- [ ] Снизить HP 150→100→50: три Hunger / три Revenant / три Brute. Новая волна через cooldown даже при 6+ живых. Проверить у стен и мебели, смерть в Summon отменяет волну.
- [ ] Длительный бой с несколькими Horde в заполненной локации: измерить CPU/GPU и число врагов. Скорость 60 FPS этим headless прогоном не подтверждается.
