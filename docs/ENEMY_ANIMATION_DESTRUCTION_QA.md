# Анимация врагов, разрушение и физика: аудит и QA

## Найденные проблемы и решения
| Проблема | Решение |
|---|---|
| Импортированные Walk/Run не зациклены | loop_mode выставляется на копиях клипов |
| Run недостижим (порог 6.8 при скорости 4.5–5.4) | порог от скорости погони, масштаб воспроизведения |
| Стойка — первый клип по алфавиту | rest-поза при остановке |
| Атака наносила урон мгновенно | урон на кадре удара, промах если цель вышла из зоны |
| Смерть без анимации | клип/поза смерти, затем погружение и скрытие |
| 6 врагов статичны и тяжёлые | процедурная анимация, лёгкие меши (в 25+ раз) |
| Обломки проходят сквозь стены/пол, нельзя расстрелять | слой 3, маска 3, исключения для персонажей |
| Осколки physical_prop без коллизии | коллизия, чанки, пыль |
| Обломки исчезают рывком, копятся | уменьшение, бюджет 40, пыль ≤ 6 |
| Обломки не наследуют движение | наследование скорости хозяина |

## Оптимизации
Далёкие враги останавливают анимацию; пыль и обломки с бюджетом; polling только
у kickable-обломков; CCD лишь для лёгких тел; облегчённые меши врагов.

## Остаточные риски (не менялось намеренно)
- Далёкие kinematic-враги могут пройти сквозь стену: нет NavigationAgent3D.
- Балансные числа новых врагов — заглушки.
- Процедурная анимация — временная, до риггованных моделей.
- Модель солдата тяжёлая, оптимизация не делалась.
- Визуальная приёмка ADR-0014 открыта (нет GPU/дисплея).

## Визуальная проверка
1. Спавн каждого врага: идёт, бежит, бьёт, умирает, тело тонет.
2. Расстрелять шкаф/стол: обломки лежат на полу, не проходят стены, игрок и враги сквозь них идут.
3. Гранатой — пыль, скорость обломков по направлению взрыва.
4. Много разрушений подряд: ≤ 40 обломков, FPS стабилен.

## Проверено автоматически
Godot 4.7.2: 15 runtime-наборов (включая два новых), main 180 кадров,
validate_project/scene_resources/architecture/workflow, Python-тесты.
