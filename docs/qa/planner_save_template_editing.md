# Save Layout и редактирование шаблонов — 18.10.2026

Область: T004, bootstrap.app. Запрос владельца — исправления в отдельной ветке и PR.

## Причины и результат

- `planning_stability._prune` типизировал ссылку до `is_instance_valid`.
  После удаления владельца маркера Godot падал на строке28 при самом присваивании.
  Проверка выполняется над Variant; обход placed и clear защищены аналогично.
- Открытие редактора заменяло прежние зоны на `Other`: проверка категории
  отменяла перемещение установленной мыши, монитора и других предметов.
  Приватный helper хранит weak session snapshots зон/переда. Размещение из
  сохранённого шаблона передаёт точные зоны через одноразовую runtime metadata,
  которую редактор потребляет. JSON карт, шаблонов и bake-сцены не расширены.
- Для старой карты без редакторского snapshot зоны восстанавливаются по типам
  связанных предметов и ближайшим опорным поверхностям. Позиции не меняются;
  пустые поверхности полок остаются доступны. Исходные имена/required/углы
  таких зон восстановить из старого DTO невозможно; созданный заново шаблон
  сохраняет уже редактируемые зоны.
- Shift+ЛКМ выбирает только attachments этого стола/полки: enclosing AABB
  корпуса больше не перехватывает выбор. Камера смотрит на рабочие поверхности.
- Контактная тень/подсветка выделения не участвует в footprint и bounds.
  Воспроизведено смещение зоны первого стола к середине между его позицией
  и ещё не обновлённой контактной тенью; synthetic overlay regression
  исключает зависимость от времени обновления тени.
