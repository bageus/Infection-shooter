# Ограниченный профиль текстур окружения

Игровые карты окружения импортируются с лимитом 1024 px и VRAM compression. Исходные изображения и GLB сохраняются. Вблизи игровые текстуры могут быть менее резкими.

Встроенные карты используют bounded_texture_post_import.gd. Его UID сохранён; GLB import profiles обновлены, чтобы запустить автоматический переимпорт. Старые производные карты остаются в игнорируемом кэше; игровые сцены ссылаются на новые ресурсы.

Загрузчик пишет этап, путь ресурса и счётчики памяти в обычный журнал. Отдельные display decals сохраняют прежний профиль.

Проверены editor import, model textures, full-map startup/restart, mission/layout/menu и project/resource/import gates. CI проверяет предел размеров игровых карт и более строгие бюджеты памяти. После обновления необходимо дождаться переимпорта и перезапустить редактор. Проверка на целевом устройстве остаётся необходимой.
