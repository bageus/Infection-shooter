# LOD мешей врагов — 09.10.2026

Инкремент T002 исправляет потерю LOD при генерации игровых мешей, скиннинге
и подготовке мешей для ран и расчленения. Владельцы состояния и публичные
контракты прежние; изменения ограничены features.infected, offline tools,
12 существующими mesh resources и runtime CI. Архитектурных исключений нет.

## Исправление

`body_part_mesh.prepare` добавляет CUSTOM0, не меняя нумерацию вершин.
Исходные LOD переносятся с точными порогами и индексами; декодирование
учитывает 16- и 32-битные индексы. Чтение выполняется только при первом
создании кэшированного меша. Базовая топология для отрыва конечностей остаётся
полной, независимо от LOD, выбранного рендерером.

`build_enemy_game_models` после уплотнения вершин генерирует LOD компактного
меша, а `build_enemy_rigs` генерирует их для меша со скиннингом. Модели и риги
имеют по 3 уровня у Hunger, 2 у Revenant/Brute/Titan/Colossus, 1 у Horde.
`build_enemy_lods.gd` добавляет LOD в существующие 12 mesh resources, не
перестраивая текстуры, скелеты и анимации. При переносе используется исходное
сериализованное содержимое поверхностей: повторное кодирование нормалей
могло бы вносить округление. Генератор проверяет исходные vertex/skin/index
streams и точное совпадение массива базового меша после переноса.

Расширять runtime helpers отдельным компонентом не требуется: подготовка
меша остаётся одной ответственностью, файл менее 300 строк. В существующем
offline генераторе ригов меняется только локальное создание mesh resource;
несвязанные этапы построения рига не затронуты.

## Проверки

До исправления новый тест воспроизводил потерю LOD; исходные игровые ресурсы
не содержали их вообще. После исправления `run_enemy_lod_tests` проверяет:

- точные LOD bytes/thresholds, 16/32-bit indices, 4/8 bone weights;
- две поверхности, материалы, отсутствие LOD, исходный меш и кэш;
- CUSTOM0 и полную топологию расчленения;
- наличие упрощённых валидных LOD во всех 12 игровых/rig resources;
- сохранность всех 17 используемых уровней в восьми готовых сценах врагов.

Тест включён в Mission runtime CI. Отдельное сравнение 12 ресурсов с Git HEAD
подтверждает точное совпадение всех полей сериализованных поверхностей кроме
LOD и неизменный AABB. Базовые vertex/normal/tangent/UV/bone/weight/index bytes
сохранены. Проверены body topology, enemy animation, dismemberment, death fall,
запуск main, editor import и project/resource/import gates (Godot 4.7.2).
FPS и переключение LOD по экранному размеру в native renderer не измерялись.

Откат: revert коммита. Пути сцен, ресурсы текстур, баланс, save/network DTO,
публичные API, зависимости и policy не менялись.
