# Просвет только для героя — 24.10.2026

Раньше mode=1 удалял фрагменты стены и крышки тумана в круге вокруг героя.
В результате становились видны раковины и потолочные светильники за стеной.
Теперь стены сохраняют цвет/depth (локальная линза только затемняет их),
а герой рисуется отдельной копией с исходными стандартными PBR параметрами.
Внутри линзы маска тумана также закрывает потолочные элементы над её плоскостью.
Реальные проёмы дверей/стёкол и обычный обзор сохраняются.

## Реализация и бюджет

Bootstrap сохраняет прежнее владение эффектом, режимы/настройку 0/1 и точное
восстановление material overrides. В mode=1 копируется только герой,
не мебель, враги или светильники. Mesh/skin/skeleton общие, morph значения
синхронизируются. Исходный scene depth маскирует уже видимые фрагменты;
сжатие clip depth сохраняет взаимное перекрытие частей героя, LIGHT_VERTEX
оставляет освещение в авторском пространстве. Основная камера, без теней.

Новых viewport, покадрового поиска предметов или физических тел нет.
Это дополнительный проход мешей одного героя и чтение scene depth; устойчивое
улучшение FPS не заявляется. Для шести wall/hero shaders прежний warm-up
добавляет четыре runtime cull variants сверх двух файловых ресурсов.
