## Стоимость рендера текстур
- Атлас группы 01: три карты 2048², ~4.67 МиБ VRAM-payload; упрощение PNG не меняет GPU-размер (фиксированный блок VRAM), уменьшает только файл.
- Выигрыш даёт отключение карт: у кожи, оружия, колонны и книг шейдер перестаёт читать 3 карты (albedo/normal/ORM), что снижает texture fetch и число уникальных текстур/VRAM только там, где карта больше не используется. Чёрный цвет сам рендер не ускоряет: блики, геометрия, draw calls, тени остаются.
- В GPU-bound сцене выигрыш возможен, при упоре в CPU/physics — малый. FPS на Windows не измерен.
