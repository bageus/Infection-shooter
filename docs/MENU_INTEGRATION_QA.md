# Меню из авторского UI kit

## Реализация

Источник: архив владельца `infection_shooter_assets_demo(1).zip` от 03.10.2026.
Используются исходные PNG main/pause/game_over/mission_complete, знак VECTRION,
шрифты DejaVu Sans и DejaVu Sans Bold. Лицензия шрифтов сохранена рядом с ними.
HTML-стенд и его демонстрационное сохранение в игру не переносятся.

Вход проекта — `menu/front_end.tscn`. Главное меню загружает существующую
боевую `main.tscn` после инструктажа. Меню принадлежат bootstrap.app;
CanvasLayer 200 закрывает HUD и не пропускает ввод в бой. Диалоги локальны,
клавиатурный фокус ограничен диалогом; ESC сначала закрывает диалог, затем паузу.
Planning mode вызывает существующий переход в редактор и не создаёт второй режим.

Общий `assets/interface/game_theme.tres` задаёт body.ttf через ProjectSettings
gui/theme/custom. В тему встроены неизменённые bytes body.ttf, чтобы избежать
зависимости загрузки project Theme от первого импорта TTF. Пересборка:
`python tools/build_interface_theme.py`; тест сверяет font data с оригиналом.
Заголовки меню используют title.ttf. HUD, дерево мутаций и
планировщик получают тот же шрифт без изменения их компоновки и игрового состояния.
Мировые Label3D подсказки оружия, ключа, DNA и двери имеют явный body.ttf;
они не полагаются на наследование Control Theme. [Godot 3D text](https://docs.godotengine.org/en/4.4/tutorials/3d/3d_text.html).

Настройки языка RU/EN, фоновой яркости меню, масштаба текста меню 100/115/130 %,
звука кнопок и его громкости сохраняются отдельно в `interface_settings.cfg`,
секция `interface_v1`. Fullscreen управляет окном Godot. Переходов в меню нет.
Это настройки интерфейса, а не сохранение кампании. Карты планировщика v6 прежние.
Project config/name сохранён: он задаёт старый user:// каталог с картами.
Видимый заголовок окна устанавливается в Infection Shooter отдельно.

Продолжение кампании и возврат к checkpoint отключены с пояснением. Перезапуск
загружает сцену заново. В паузе возврат в меню и перезапуск требуют игрового
подтверждения, чтобы не потерять текущую попытку случайным кликом. При выходе
с этажа фон успеха сообщает «Этаж пройден», не о завершении всей кампании.
В Web кнопка выхода показывает подсказку о закрытии вкладки.

## Автоматическая проверка

- run_menu_tests: старт → инструктаж → бой → пауза → настройки → возврат;
  Planning mode → выход; поражение → успех этажа → restart → главное меню;
  локализация, сохранение настроек, 130 % текст, клавиатурный фокус и общий шрифт.
- CI: headless import, общий валидатор, ресурсы, существующие runtime-наборы,
  основной бой 180 кадров. Новый вход не подменяет прежний smoke test боевой сцены.
- capture_menu_screens: реальные кадры Godot Compatibility через Xvfb,
  1280×720, четыре экрана и настройки; artifact `menu-previews`.

Godot 4.7.2, implementation CI https://github.com/bageus/Infection-shooter/actions/runs/37154864305:
menu integration — 0 failures, остальные 18 наборов сообщили ноль assertions failures;
main 180 кадров PASS; gates/resources/architecture PASS. Реальные кадры Compatibility
1280×720 (четыре экрана, настройки, 130 %, HUD и planner) проверены. Новые ошибки
cold-import theme/font устранены; прежние FBX palette1.png/couches.png и duplicate
Idle_Pistol_Down_001 остаются (import exit 0, не чистый import).

Общий runtime job FAIL: после нулевых failures world_bindings сообщает
`1 resources still in use at exit`. Это воспроизведено в исходном main 26a819a,
run 37148645355; ошибка не подавлена, внесена в BACKLOG. Для завершения проверки
цикл CI теперь выполняет все наборы и возвращает накопленный ненулевой статус.
Убрана случайность corpse fixture: обычная смерть Hunger вместо 500 damage,
запускавшего blast severing до проверки отстрела ноги. Игровой код расчленения прежний.

## Проверка на целевой машине

1. Запустить проект: главное меню из архива, без панели «Интерактивный макет».
2. Мышь, ↑/↓, Tab, Enter/Space, ESC: выбор, подтверждение, отмена; фон не крадёт ввод.
3. В меню и паузе сменить RU/EN, масштаб и яркость; перезапустить игру и проверить настройки.
4. Начать операцию; убедиться, что HUD, дерево мутаций и палитра редактора используют DejaVu Sans.
5. Открыть паузу; время, заражение и враги стоят. Planning mode открывает существующий редактор.
6. Проверить return/restart, оба результата, 1280×720, 1920×1080 и desktop Web.

Ограничения: исходные фоны 822×463/467, при большом окне мягкие; текст остаётся
чётким. Кампания/checkpoints и полный перевод игрового HUD — отдельные задачи.
